MiniWeb Server Language (MWSL) page, with 2 variables

If values are empty, check the Page Source by right clicking on the page and selecting View page Source...

If you get something like:

<!-- *** SCRIPT ERROR *** ---
Unknown Variable: Температура.

It means your FWX does not support HTTP variables, and you need to add the following to the Table Of Contents entries from which both exist:

  1. WEBLINK exists in the file? TRUE
  2. FUNC_STARTPROC exists in the file? TRUE

If on the other hand you get something like:

<!-- *** SCRIPT ERROR *** ---
Script error detected at position 29 in line:
<!--
                             ^- Parse Position
Error: Error calling function \'GetVar\' result d4810013.

It means that HTTP is supported but either this variable name does not exist, or you are trying to read an array variable (with brackets []) which is impossible to accomplish with HTTP according to Simatic HMI HTTP Protocol rules.

Note: There is a size limit for the HTML page, thus you must split it to a few smaller files or else only part of the data will be returned from the MiniWeb server
