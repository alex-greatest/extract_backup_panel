# Структура кода FlexRt

Решение `FlexRt.sln` — четыре проекта .NET:

- `src/FlexRt.Core/` — библиотека-ядро: разбор, сопоставление, экспорты и
  сценарий запуска. В консоль не пишет и Serilog не знает.
- `src/FlexRt/` — консоль: `Program.cs` (пути, лог) и `LogReporter`
  (события запуска в лог); в консоль ничего не печатает.
- `src/FlexRt.Ui/` — окно просмотра (WPF + BlazorWebView, компоненты
  Radzen.Blazor, `net10.0-windows10.0.17763.0`): показывает экраны панели,
  таблицы листов и текст чтения (`RunTranscript`), читает данные ПЛК по выбору,
  по кнопкам сохраняет книги Excel.
- `tests/FlexRt.Tests/` — тесты xUnit; ссылаются на ядро и консоль.

Папки ядра разделяют ответственность внутри проекта. Namespace совпадает с
путём папки: `Parsing/Plc/Plf/Tags/` — `FlexRt.Parsing.Plc.Plf.Tags`.

## Как данные проходят через приложение

`Program.cs` вызывает `ExtractionRun.Execute` с путями и `LogReporter`.
`ExtractionRun` выполняет шаги ниже и сообщает о каждом событием
`IExtractionReporter`; итог — `ExtractionResult` с кодом возврата.

1. `FwxReader.Read` читает `pdata.fwc`: заголовок, TOC,
   затем `STRINGSTORE`, `VAR`, `DATALINK_READWR`, `DATALINK`,
   `CONNECTION_OMSP`, `DEVICE_OMSP`, `SYSMSGHANDLER`, `MSG_NUMHANDLER`,
   `MSG_NUMEVENT`, `AREAPTR`, `MSG_ANALOGHANDL`, `MSG_ANALOGCREAT`,
   `MSG_ANALOG_OBSE`, `RECMSG`, `ARCHIVES`, `MSG_LOGGER`, `FUNC_SEND_EMAIL`,
   `SCREEN`, `ADAPTVALUECHANG`, `GUI`, `PICTURE`, `TILED_PICTURE`.
   Результат — `FwxDocument`.
   `PanelFilesReader.Read` берёт модель панели и версию Runtime из файлов
   рядом с `pdata.fwc`.
2. `PlcDataReader.Read` (общий с окном шаг) проверяет «не поддерживается»,
   читает проект ПЛК, сопоставляет теги и сообщает ошибки ПЛК.
   `PlfReader.Read` читает проект ПЛК `PEData.plf`: ПЛК и их IP, теги ПЛК,
   DB; если путь ПЛК — папка, `CardReader.Read` читает карту ПЛК
   (`SIMATIC.S7S\OMSSTORE`). Результат обоих — `PlcProject`.
   `TagMatcher.Match` находит для каждого тега панели тег или член DB ПЛК.
3. Четыре независимых экспорта: `panel_data.xlsx` (листы «Сводка», «Теги»,
   «Системные события», «Дискретные алармы», «Аналоговые алармы», «Классы
   алармов», «Группы алармов», «Экраны», «Ошибки»),
   `PDATA.xlsx`, hex-файлы, картинки (папка `images`).
   Строки листов сначала строятся без Excel (`ReportTable` из `*Table`,
   `SummaryRows`); какие листы `panel_data.xlsx` есть и в каком порядке,
   описывает `PanelDataBook`, на лист их пишет `ReportSheetsExporter`.

## Зависимости

`Binary` ← `Model` ← `Parsing` ← `Export` ← `Extraction` ← консоль
(`Program.cs`, `LogReporter`) и окно. Модели — только данные. Ядро не пишет в
консоль. Окно просмотра ссылается на `FlexRt.Core`, `ExtractionRun` не вызывает:
`PanelLoader` читает панель `FwxReader.Read`, текст чтения собирает `RunTranscript`
(`PanelRead`, затем `PlcDataReader.Read`, если выбраны данные ПЛК), экраны
берёт из `ScreensTable` (строки листа «Экраны», `ScreenCount`), разделы листов —
из описания книги `PanelDataBook` (те же листы, условия и порядок, что у
консоли; каждый лист строится отдельно — `TryBuild`), теги сопоставляет
сопоставлением из `PlcDataReader`, а без данных ПЛК — `TagMatcher.Match` без
проекта ПЛК; группировку текстов по языкам повторяет у себя (`PanelViews`). Значения вида
экрана и заголовки колонок Name и Start screen окно повторяет у себя
(`ScreenKind`, `StartScreenColumn`): нет колонки Name или строк не столько,
сколько экранов, — `ScreenItems` бросает исключение и файл не открывается;
экран нового вида попадает в папку «Вид не опознан». Сохраняет окно через ядро:
`panel_data.xlsx` и лист — `ReportSheetsExporter` из таблиц разделов, `PDATA.xlsx` —
`XlsxExporter`; листы всей книги — разделы `PanelView.Book` в порядке `PanelDataBook` (`PanelDataSheets`). `Parsing/Panel` и `Parsing/Plc` друг от друга не зависят, общее у них —
`Parsing/Codes`. `Parsing/Plc` наружу отдаёт только `PlfReader` и
`CardReader`, остальное — `internal`.

## Если добавлять извлечение новых данных

Новая таблица панели: модель записи в `Model/Panel/` (алармы и классы — в
`Model/Panel/Alarms/`), список в `FwxDocument`, парсер в `Parsing/Panel/`
(алармы и классы — в `Parsing/Panel/Alarms/`) через `FwxDocument.FindTable` и
`FwxReader.CheckedItems`, строка `TryParse` в `FwxReader.Read`. Новые данные
проекта ПЛК: парсер в подпапке `Parsing/Plc/` по роли, объекты — через
`PlfFile`, связи — `PlfRelations.Scan`, подключение — в `PlfReader.Read`
(`Parsing/Plc/Plf/`); данные карты ПЛК — в `Parsing/Plc/Card/`, подключение —
в `CardReader.Read`.
Новые колонки листа «Теги» заполняются в `Export/PanelData/Tags/TagRowFormatter`. Число в сводку:
строка текста запуска — в `RunTranscript.PanelRead` (и в лог — `LogReporter.PanelRead`),
строка листа — в `SummaryRows`.

Таблицы с одинаковым именем бывают (`PS_BorderedShap`, `Id` 0x161 и 0x169):
`FindTable` вернёт первую. Форматы описаны в `docs/формат-fwx/`,
`docs/формат-plf/` и `docs/формат-карты/`.
