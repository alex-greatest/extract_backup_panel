# Структура кода FlexRt

FlexRt — одно консольное приложение .NET. Папки `src/FlexRt/` разделяют
ответственность внутри проекта; отдельными библиотеками они не являются.
Namespace совпадает с путём папки: `Parsing/Plc/Tags/` —
`FlexRt.Parsing.Plc.Tags`.

## Как данные проходят через приложение

1. `Program.cs` вызывает `FwxReader.Read` для `pdata.fwc`: заголовок, TOC,
   затем `STRINGSTORE`, `VAR`, `DATALINK_READWR`, `DATALINK`,
   `CONNECTION_OMSP`. Результат — `FwxDocument`.
2. `PlfReader.Read` читает проект ПЛК `PEData.plf`: ПЛК и их IP, теги ПЛК,
   DB. Результат — `PlcProject`.
3. `TagMatcher.Match` находит для каждого тега панели тег или член DB ПЛК.
4. Три независимых экспорта: `panel_data.xlsx`, `PDATA.xlsx`, hex-файлы.

## Папки

```
Binary/                       чтение байтов с проверкой границ, FwxFormatException
Model/    Panel/              FwxDocument, HmiTag, PlcLink, HmiConnection, …
          Plc/                PlcProject, PlcDevice, PlcTag, PlcDb, PlfObject, …
          Matching/           PlcMatch, PlcLookup, DbResolution
Parsing/  Panel/              FwxReader, StringStoreParser, VarParser,
                              DatalinkReadWrParser, ConnectionParser
          Plc/                PlfReader, PlfFile, PlfFormat, PlfText, PlfRelations
              Tags/           PlfTagParser, PlfTagNames
              Devices/        PlfDeviceParser
              DataBlocks/     PlfDbReader, PlfInterfaceReader, PlfInterfaceXml,
                              PlfXmlBytes, PlfMemberComments
          Codes/              PlcAreaCodes, PlcTypeCodes, PlcAddress, PlcMemberTypes
          Matching/           TagMatcher, DbPathResolver
Export/   Tags/               PanelDataExporter, TagRowFormatter, TagTypeNames
          Strings/            XlsxExporter
          Hex/                HexExporter
          ExcelCell           обрезка текста ячейки для обоих Excel
Program.cs                    пути, сводка, экспорты
```

## Зависимости

`Binary` ← `Model` ← `Parsing` ← `Export` ← `Program.cs`. Модели — только
данные. `Parsing/Panel` и `Parsing/Plc` друг от друга не зависят, общее у них —
`Parsing/Codes`. `Parsing/Plc` наружу отдаёт только `PlfReader`, остальное —
`internal`.

## Если добавлять извлечение новых данных

Новая таблица панели: модель записи в `Model/Panel/`, список в
`FwxDocument`, парсер в `Parsing/Panel/` через `FwxDocument.FindTable` и
`FwxReader.CheckedItems`, строка `TryParse` в `FwxReader.Read`. Новые данные
проекта ПЛК: парсер в подпапке `Parsing/Plc/` по роли, объекты — через
`PlfFile`, связи — `PlfRelations.Scan`, подключение — в `PlfReader.Read`.
Новые колонки листа «Теги» заполняются в `TagRowFormatter`.

Таблицы с одинаковым именем бывают (`PS_BorderedShap`, `Id` 0x161 и 0x169):
`FindTable` вернёт первую. Форматы описаны в `docs/формат-fwx/` и
`docs/формат-plf/`.
