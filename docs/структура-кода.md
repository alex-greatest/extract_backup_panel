# Структура кода FlexRt

FlexRt — одно консольное приложение .NET. Папки `src/FlexRt/` разделяют
ответственность внутри проекта; отдельными библиотеками они не являются.

## Как данные проходят через приложение

`Program.cs` вызывает `FwxReader.Read`. Читатель открывает FWX, читает
заголовок и список таблиц (TOC), затем извлекает строки из `STRINGSTORE`.
Результат хранится в `FwxDocument`. После чтения два независимых экспортёра
записывают языковые строки в XLSX и все таблицы TOC в hex-файлы.

## За что отвечает каждая часть

Каждая папка отвечает за один слой чтения или записи и использует только
соседние слои, перечисленные ниже.

- [`Binary/`](../src/FlexRt/Binary/FwxBinary.cs) читает числа и строки из
  байтов файла, проверяет границы. `FwxFormatException` сообщает секцию и
  смещение ошибки.
- [`Model/`](../src/FlexRt/Model/FwxDocument.cs) хранит результат чтения:
  заголовок, таблицы TOC, языковые строки и предупреждения. Здесь же лежат
  модели отдельных записей и элементов таблиц.
- [`Parsing/FwxReader.cs`](../src/FlexRt/Parsing/FwxReader.cs) читает общую
  структуру FWX и определяет границы таблиц. Его `Items` обходит элементы
  таблицы, если она имеет заголовок `0x34` и каталог смещений.
- [`Parsing/StringStoreParser.cs`](../src/FlexRt/Parsing/StringStoreParser.cs)
  разбирает строки таблицы `STRINGSTORE`. Других семантических парсеров
  таблиц сейчас нет.
- [`Export/`](../src/FlexRt/Export/) записывает результаты. `XlsxExporter`
  создаёт книгу языковых строк, а `HexExporter` — hex-файлы всех таблиц
  TOC, включая `VAR` и `DATALINK_READWR`.
  [`Program.cs`](../src/FlexRt/Program.cs) задаёт три статичных пути,
  печатает сводку и запускает два экспорта независимо друг от друга.
- Файлы справочника типов и HTML-шаблоны удалены, ресурсное копирование
  отключено; пустая папка `Resources/` не используется.

## Если добавлять извлечение новых данных

Общий каркас уже можно использовать повторно: `FwxReader` прочитает TOC,
парсер найдёт нужную таблицу через `FwxDocument.FindTable`, а `FwxBinary`
прочитает её поля с проверкой границ. `FwxDocument.HasTable` позволяет
проверить наличие таблицы без извлечения записей. Для новой таблицы
понадобятся её модель, список записей в `FwxDocument` и парсер, подключённый
в `FwxReader.Read`.
Если нужен новый выходной файл, понадобится отдельный экспортёр и его вызов
из `Program.cs`.

Например, для извлечения картинок сначала нужно установить по байтам
настоящего FWX, где они лежат и как записаны. `FwxReader.Items` пригодится
только при той же структуре таблицы с каталогом смещений. Текущий
`HexExporter` сохраняет текстовый hex, а не готовые файлы изображений;
парсера картинок сейчас нет. `FwxBinary` не отдаёт исходный диапазон байтов
для записи бинарного файла, поэтому для такого экспорта потребуется добавить
чтение диапазона. Синтетический `samples/sample.fwx` не подтверждает формат
картинок.
