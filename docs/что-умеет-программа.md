# Что умеет программа

Обновлено: 8 октября 2026.

## Нужно на входе

- Бэкап панели (`pdata.fwc`) — обязательно.
- Данные ПЛК — по желанию, одно из двух; дают имена и комментарии ПЛК:
  - проект ПЛК (`PEData.plf`) из TIA;
  - копия карты памяти ПЛК — папка, в которой лежит `SIMATIC.S7S`.

## Умеем

- Все HMI-теги: имя, тип, соединение, адрес, режим доступа, цикл.
- С проектом или картой ПЛК: имя ПЛК, тег ПЛК, комментарий из ПЛК.
- С карты имя ПЛК берётся из имени папки карты: своего имени ПЛК на карте нет.
- Строки всех языков панели.
- Сверху листа «Теги» — статистика: сколько тегов, сколько найдено в ПЛК,
  сколько есть в панели, но нет в ПЛК, внутренних, с абсолютной адресацией,
  для скольких данные ПЛК неизвестны.
- Первый лист «Сводка»: модель панели, версия Runtime, IP панели, соединения и
  IP ПЛК, откуда данные ПЛК, имя ПЛК, модель CPU (с карты), число тегов и DB.
- У тегов с абсолютным адресом в DB в PLC tag — имя DB (`AlarmsDB`).

## Не умеем

- Comment HMI-тега — его нет ни в бэкапе, ни в ПЛК; колонка убрана.
- Logged и Tag table.
- Несколько ПЛК из отдельных выгрузок.
- С карты: выбрать ПЛК по IP, если у панели несколько соединений.
- Модель CPU из `PEData.plf`; версию Runtime из папки `Generates` проекта TIA
  (файла `BuildInfo.txt` там нет).

## Не проверено

- HMI-тег целиком с типом UDT.
- TIA кроме V17/V19/V21, панели кроме TP700 и TP1500, ПЛК кроме S7-1500/1200.
- Карта ПЛК: проверена одна (S7-1500F, данные TIA V19); S7-1200, карты
  других версий TIA и с защитой ноу-хау не проверены. Сверено только по
  именам HMI-тегов, проекта TIA этой карты нет.
