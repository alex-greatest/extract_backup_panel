# Что умеет программа

Обновлено: 10 октября 2026.

## Нужно на входе

- Бэкап панели (`pdata.fwc`) — обязательно.
- Данные ПЛК — по желанию, одно из двух; дают имена и комментарии ПЛК:
  - проект ПЛК (`PEData.plf`) из TIA;
  - копия карты памяти ПЛК — папка, в которой лежит `SIMATIC.S7S`.

## Умеем

- Все HMI-теги: имя, тип, соединение, адрес, режим доступа, цикл.
- С проектом или картой ПЛК: имя ПЛК, тег ПЛК, комментарий из ПЛК.
- С карты имя ПЛК — имя CPU из конфигурации оборудования (`TM50`); не нашлось — имя папки карты.
- Строки всех языков панели.
- Системные события (HMI alarms → System events): лист «Системные события» —
  ID и текст на каждом языке панели, по возрастанию ID. Сверено с TIA: Project1
  (английский) и A603A0097 (английский, русский, польский) — все 585 совпали.
- Текст, начинающийся с апострофа (`'Project ID' area pointer…`), попадает в
  Excel целиком, с апострофом.
- Сверху листа «Теги» — статистика: сколько тегов, сколько найдено в ПЛК,
  сколько есть в панели, но нет в ПЛК, внутренних, с абсолютной адресацией,
  для скольких данные ПЛК неизвестны.
- Первый лист «Сводка»: модель панели, версия Runtime, IP панели, соединения и
  IP ПЛК, откуда данные ПЛК, имя ПЛК, модель CPU и IP CPU (с карты), число тегов и DB.
- У тегов с абсолютным адресом в DB в PLC tag — имя DB (`AlarmsDB`).

- HMI-тег с пользовательским типом: TIA кладёт в панель только используемые
  элементы, отдельными тегами (`xxxx_1.Element_1`); они находятся в ПЛК — член
  DB и член тега входов (`1.Element_1`). Неиспользуемых элементов в бэкапе нет.
  Проверено и с `PEData.plf`, и с карты ПЛК — результат одинаковый.

## Не умеем

- Comment HMI-тега — его нет ни в бэкапе, ни в ПЛК; колонка убрана.
- Пользовательские алармы (Discrete, Analog) — ещё не разобраны. У системных
  событий — только ID и текст, других свойств нет.
- Logged и Tag table.
- Несколько ПЛК из отдельных выгрузок.
- Панель с несколькими соединениями с ПЛК вместе с данными ПЛК (`PEData.plf`
  или карта) — пока сознательно не поддерживается: сообщение, файлы не
  создаются. Без данных ПЛК такая панель читается.
- Модель CPU из `PEData.plf`; версию Runtime из папки `Generates` проекта TIA
  (файла `BuildInfo.txt` там нет).

## Не проверено

- TIA кроме V17/V19/V21, панели кроме TP700 и TP1500, ПЛК кроме S7-1500/1200.
- Карта ПЛК: реальная CCB-A03 (S7-1500F, TIA V19) и тестовая из своего проекта (V21) —
  по ней результат совпал с `PEData.plf` один в один; S7-1200, карты
  других версий TIA и с защитой ноу-хау не проверены. Сверено только по
  именам HMI-тегов, проекта TIA этой карты нет.
- Системные события: зачем в A603A0097 у 3 событий есть лишняя запись в конце
  таблицы, неизвестно.
- Бэкап, скомпилированный старой версией TIA, может содержать меньше системных
  событий, чем показывает проект сейчас: в копиях A603A0097 от 30 мая нет 5
  событий 220010…220014, после перекомпиляции они появились.
