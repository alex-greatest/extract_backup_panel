# Что умеет программа

Обновлено: 7 октября 2026.

## Нужно на входе

- Бэкап панели (`pdata.fwc`) — обязательно.
- Проект ПЛК (`PEData.plf`) — по желанию, даёт имена и комментарии ПЛК.

## Умеем

- Все HMI-теги: имя, тип, соединение, адрес, режим доступа, цикл.
- С проектом ПЛК: имя ПЛК, тег ПЛК, комментарий из ПЛК.
- Строки всех языков панели.

## Не умеем

- Comment HMI-тега — его нет в бэкапе.
- Logged и Tag table.
- Несколько ПЛК из отдельных выгрузок.
- Программу с карты памяти ПЛК.

## Не проверено

- HMI-тег целиком с типом UDT.
- TIA кроме V17/V21, панели кроме TP700, ПЛК кроме S7-1500/1200.
