# Документация FlexRt

FlexRt читает скомпилированную конфигурацию панели из TIA Portal
(`pdata.fwc`) и, если выбраны, проект ПЛК или копию карты ПЛК; извлекает теги,
системные события, дискретные и аналоговые алармы, классы и группы алармов,
экраны, картинки и строки языков. Программа — окно просмотра: показывает экраны
панели, таблицы листов обеих книг Excel, картинки и текст чтения; книги Excel и
картинки пишет только по кнопкам сохранения. Консольной программы нет (удалена
20 октября 2026). Код и его XML-документация — главный источник фактов о
формате.

## Что где лежит

`AGENTS.md` и `CLAUDE.md` в корне репозитория (одинаковые) и `.claude/rules/` —
правила для агента, а не документация для читателя: в `CLAUDE.md` — правила
работы, кодирования и обязательные проверки, в `.claude/rules/` — установленное
поведение и ограничения по областям. При расхождении между `docs/` и правилами
агента правилом считаются они.

Каталог `docs/` изменяется только по прямому запросу владельца проекта.
