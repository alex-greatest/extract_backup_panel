# Окно просмотра

Окно показывает панель из `pdata.fwc`: дерево проекта, экран в его размере,
таблицы листов `panel_data.xlsx` и `PDATA.xlsx`, свойства выбранного и текст
чтения, который раньше печатала консоль. Данные ПЛК — по выбору. Файлы рядом
с `pdata.fwc` не читаются; пишутся только книги Excel по кнопкам. Нужны Windows и WebView2.

Запуск из корня репозитория: `dotnet run --project src/FlexRt.Ui`.

## Открыть панель

- Кнопка «Открыть pdata.fwc…» — стандартный диалог Windows, фильтр `*.fwc` и
  «Все файлы». Отмена ничего не меняет.
- Пока файла нет, во всех панелях — «Откройте pdata.fwc»; во время чтения —
  «Чтение файла…», кнопки заняты, прежняя панель убирается сразу.
- Файл не читается — в строке состояния «Файл не прочитан: <причина>», на
  вкладке «Ошибки» — `Не удалось прочитать <путь>: <причина>`. Файл прочитан, но
  упал следующий шаг — панель не открывается, там же `ОШИБКА: <шаг>: <причина>`
  (например, «данные ПЛК не обработаны»).
- После чтения выбран стартовый экран, а если его нет — первый.

## Данные ПЛК

- Кнопка «Данные ПЛК» — меню: «Файл PEData.plf…» (диалог файла, фильтр
  `*.plf`), «Карта ПЛК…» (диалог папки с `SIMATIC.S7S`), «Без данных ПЛК».
  Рядом — выбранный путь или «не заданы». Отмена диалога ничего не меняет.
- Выбор запоминается до закрытия окна; открытая панель перечитывается с ним.
- С данными ПЛК теги, дискретные алармы и «Сводка» — как в консоли с теми же
  данными; на Info — строка `Файл ПЛК: …`, на «Ошибках» — предупреждения ПЛК.
- Панель с несколькими соединениями и выбранными данными ПЛК — на «Ошибках»
  `ОШИБКА: не поддерживается: …; панель показана без данных ПЛК`, панель —
  без данных ПЛК.

## Дерево проекта

- корень — имя файла; «Сводка»; HMI tags;
- HMI alarms → Discrete alarms, Analog alarms, System events, Alarm classes,
  Alarm groups — только разделы, чьи листы есть в книге;
- Screens — обычные экраны; щелчок по папке — таблица листа «Экраны»;
- Screen management → Pop-up screens, Slide-in screens, Permanent area;
- «Вид не опознан» — экраны вида `?`; «Тексты» → по разделу на язык.

Справа от раздела — число строк его таблицы, у Screens — строк листа
«Экраны». Стартовый экран помечен `▶`. Щелчок по экрану или разделу показывает
его; по другой папке или корню только подсвечивает узел.

## Экран

- Заголовок — `pdata.fwc ▸ <вид> ▸ <имя>`; экран — пустой прямоугольник его
  размера, масштаб 25–200 %.
- Свойства: General — Name, Number, Start screen (флажок), Вид; Layout —
  Width, Height. Animations и Events — «не разобрано».

## Раздел

- Заголовок — `pdata.fwc ▸ HMI alarms ▸ Discrete alarms`.
- Таблица — те же колонки и строки, что на листе; без данных ПЛК колонки ПЛК
  тегов — «неизвестно». Над HMI tags — статистика, как вверху листа «Теги».
- Сортировка щелчком по заголовку, фильтр под заголовком: в тексте — «содержит»
  без учёта регистра, в числах — «равно». Ширину колонок можно менять.
- Первая строка выбрана сразу; в свойствах — все ячейки строки под
  заголовками колонок. Фильтр скрыл выбранную строку — выбор снимается.
- Ctrl+C — выбранная строка в буфер через Tab.
- «Сводка» — список «подпись — значение», как на листе; модель панели и
  версия Runtime — «неизвестно», «Данные ПЛК» без данных ПЛК — «не задан».
- Ядро не смогло построить таблицу — у раздела в дереве ⚠, вместо таблицы
  «Раздел не построен: <причина>», то же на вкладке «Ошибки».

## Сохранить в Excel

- «panel_data.xlsx» — меню «Вся книга…» и «Текущий лист…» (раздел книги, не экран
  и не язык); «PDATA.xlsx…» — тексты всех языков. Диалог «Сохранить как», папка —
  прошлого сохранения, сначала — папка `pdata.fwc`; отмена ничего не меняет.
- В файле — то, что показано: «Сводка» как в окне, листа «Ошибки» нет; «Теги» —
  и без тегов; раздел, который не построен, пропускается и назван в уведомлении.
- Итог — уведомление «Сохранено» и путь; ошибка записи — и в строке состояния.

## Info, «Ошибки», уведомление и строка состояния

- Info — основной текст чтения, как его печатала консоль, без строк экспортов
  и без ошибок: файл, таблицы TOC, числа, стартовый экран, `Файл ПЛК: …`
  (только с выбранными данными ПЛК). Моноширинный шрифт.
- «Ошибки» — предупреждения (жёлтые, ⚠) и ошибки (красные, ⛔) того же текста,
  затем разделы, которые не построены. На заголовке вкладки — иконка и число
  строк: красные, если есть хоть одна ошибка, жёлтые — если одни предупреждения,
  нет ничего — без иконки и числа.
- После открытия с ошибками или предупреждениями на 6 с всплывает уведомление
  в правом верхнем углу: «Есть ошибки» (красное) или «Есть предупреждения»
  (жёлтое), `N — вкладка «Ошибки»`. Вкладка сама не переключается.
- Строка состояния: путь, «Строк: N из M» у таблицы, `Экранов: N`,
  «Предупреждений и ошибок: N (вкладка «Ошибки»)», «Строка не скопирована: …»,
  если буфер занят.

## Чего нет

- Объектов на экранах, шаблона экрана, анимаций и событий.
- Листа «Ошибки» `panel_data.xlsx` (ошибки ПЛК — на вкладке «Ошибки»), картинок.
- Выгрузки hex таблиц и картинок: их делает только консольная программа.
- Правки: окно ничего не меняет в `pdata.fwc`.
