# Окно просмотра

FlexRt показывает панель из `pdata.fwc`: дерево проекта, экраны, таблицы `panel_data.xlsx` и `PDATA.xlsx`, картинки, свойства и текст чтения.
Данные ПЛК — по выбору. Соседние `.pwx`/`.pwl*` дают имена пользователей, группы и время автовыхода; пароли не возвращаются.
Файлы пишутся только по кнопкам. Нужны Windows и WebView2. Запуск: `dotnet run --project src/FlexRt.Ui`.

## Открыть панель

Кнопка «Открыть pdata.fwc…» вызывает диалог Windows с фильтрами `*.fwc` и «Все файлы»; отмена ничего не меняет.
- До открытия — «Откройте pdata.fwc»; при чтении — «Чтение файла…», кнопки заняты, прежняя панель убрана.
- Файл не прочитан: строка состояния — «Файл не прочитан: <причина>», «Ошибки» — `Не удалось прочитать <путь>: <причина>`.
- Сбой следующего шага: панель не открывается, там же `ОШИБКА: <шаг>: <причина>` (например, «данные ПЛК не обработаны»).
- После чтения выбран стартовый экран, а если его нет — первый.

## Данные ПЛК

Меню «Данные ПЛК»: «Файл PEData.plf…» (файл `*.plf`), «Карта ПЛК…» (папка с `SIMATIC.S7S`), «Без данных ПЛК».
Рядом — путь или «не заданы»; отмена не меняет выбор. Выбор действует до закрытия окна, открытая панель перечитывается.
Теги, дискретные алармы и «Сводка» дополняются именами, адресами и комментариями ПЛК; на Info — `Файл ПЛК: …`, на «Ошибках» — предупреждения ПЛК.
Несколько соединений панели с выбранными данными ПЛК: `ОШИБКА: не поддерживается: …; панель показана без данных ПЛК`; панель остаётся без данных ПЛК.

## Дерево проекта

Корень — имя файла. Разделы появляются, если соответствующие данные есть в книге:
- «Сводка»; HMI tags; HMI alarms → Discrete alarms, Analog alarms, System events, Alarm classes, Alarm groups.
- Screens — обычные экраны; папка открывает таблицу «Экраны». Screen management → Pop-up screens, Slide-in screens, Permanent area.
- «Вид не опознан» — экраны вида `?`; «Картинки»; «Тексты» → языки; User administration → Users и группы пользователей.
Users показывает Name, Automatic logoff и Logoff time (минуты), группы — Number, Display name и права. Нет прочитанного `.pwx`/`.pwl*` — только группы и причина на «Ошибках».
Справа — числа строк, картинок, вложенных экранов, списков алармов и языков. Стартовый экран помечен `▶`.
Щелчок по экрану, разделу или «Картинкам» открывает их; по папке или корню — подсветка, кроме папки Screens.

## Экран и свойства

Заголовок — `pdata.fwc ▸ <вид> ▸ <имя>`. Холст — размер и цвет экрана, сверху обычного экрана — затемнённая Permanent area.
- Объекты — по X, Y, Width, Height. I/O field рисуется с фоном, рамкой, шрифтом, выравниванием и Margins. Холст показывает прочитанное оформление ненажатой кнопки, поворачивает текст и учитывает выравнивание и отступы подписи. Прочие объекты показаны синими рамками с именами.
- Числовой образец — нули; Units без добавленного пробела. Date/Time — образец редактора `2002-12-31 10:59:59` в формате выбранного языка, значения тегов не используются.
- Обрезка по Margins допускает части символов; ширины букв и начало центрированной строки — в целых пикселях.
- Не прочитана рамка — объекта нет; вышла за экран — рисуется. Оба случая дают предупреждение на «Ошибках».
- Первый щелчок выбирает самый маленький объект под курсором, при равной площади — верхний; видны маркеры по углам и свойства справа.
- Повторные щелчки в той же точке (допуск 3 px) перебирают объекты по кругу, включая большой под маленьким и тонкую линию. Другая точка — снова самый маленький, пустое место — экран.
- Масштаб — 25–200 %. Permanent area высотой 0 или непрочитанной — подсказка; область с экраном выше панели — жёлтое примечание (экраны не пересохранены после смены высоты).
Панели свойств устроены одинаково: слева Property list, справа серые блоки с заголовками и плоскими полями; недоступные поля серые. Активная вкладка светлее.
У I/O field — свойства General, Appearance, Characteristics, Layout, Text format, Flashing, Limits, Miscellaneous, Security и Styles/Designs. [Полный перечень](../что-умеет-программа.md).
У кнопки — **General** с режимом и подписями, **Appearance** с цветом текста, рамкой и образцом заливки, **Fill pattern** с основным цветом и переходами, **Design → Focus** с шириной и цветом рамки фокуса. В **Layout** видны координаты, размеры, отступы текста и картинки, выравнивание и растягивание картинки. В **Text format** видны шрифт, ориентация и выравнивание текста. В **Security** видны право **Authorization** и флажок **Allow operator control**. [Все свойства и ограничения кнопки](../что-умеет-программа.md).
Flashing — Disabled/Standard и Flash on limit violation; данных нет — «Нет в файле», цепочка повреждена —
«не прочитано» и предупреждение. В Limits только цвета High/Low limit violated.
Вкладки I/O field: Animations — Appearance, Control enable, Visibility и движения; Events — Activate,
Deactivate, OnFinishInput с функциями (у Output сообщение об отсутствии событий в файле).
Texts — непустые Tooltip всех языков Runtime и ссылка `ObjectName\Tooltip`. Выбранный раздел свойств сохраняется при смене объекта. Холст анимации не воспроизводит.
У экрана General показывает Name, Number, Start screen, цвет фона с образцом и Вид, справа Tooltip с переносами; Layout — Width, Height.
Animations экрана — Visibility (Tag, Range from, To, Visible/Invisible), без неё «Анимаций нет». Events —
Loaded/Cleared слева (пустое серым), справа функции с раскрываемыми параметрами; кнопки панели неактивны.
Тег параметра — по имени (`?`, если не найден), объект экрана — по имени, журнал/отчёт/текстовый список — номером
(`журнал #2`). Одинаковые байты — имена через « / », неизвестная функция — `FUNC_X (подкод 0x3)`.
Непрочитанные событие/функция — «не прочитано» и предупреждение. Подробнее о свойствах — [возможности программы](../что-умеет-программа.md).
Проверка: TIA V21 Update 1, TP700 Comfort; Date/Time — en-US/de-DE/ru-RU, Tahoma Bold 13/16/23/25 и Double line 1–6 при 100 %. Сглаживание отличается, границы текста — до 1 px.
Flashing Standard проверен у Input/output и Output; мигание по пределам — с прямым/мультиплексированным тегом и Appearance. Другие версии и физическая панель не проверены.

## Таблицы разделов

Заголовок — например `pdata.fwc ▸ HMI alarms ▸ Discrete alarms`; таблица содержит колонки и строки листа. Над HMI tags — статистика; без данных ПЛК его колонки — «неизвестно».
- При нескольких языках справа — «Все языки» или один язык: видны его колонки, Alarm class — на нём (в
  Excel первый язык). После открытия выбран первый язык, данные ПЛК его не меняют.
- Выбор языка общий; скрытые колонки теряют фильтр и сортировку. В свойствах строки, Ctrl+C и файлах сохраняются все языки; узлы «Тексты → язык» не меняются.
- Для смены языка выберите его, например в System events, и вернитесь на экран. Меняются Tooltip и Date/Time у I/O field и
  шрифт на холсте и в **Text format → Font** у поля и кнопки. При выборе «Все языки» или отсутствии шрифта языка виден первый шрифт объекта.
- Сортировка — по заголовку; фильтр текста — «содержит» без учёта регистра, числа — «равно»; ширины колонок меняются.
- Первая строка выбрана сразу; свойства показывают ячейки под заголовками. Фильтр скрыл строку — выбор снят. Ctrl+C — строка через Tab, многострочное в кавычках.
- У HMI tags: General — ячейки строки, Range — Upper 2/Upper 1/Lower 1/Lower 2, число или имя тега и Const/Tag.
  Выключено — «не задано», нет записи — «нет данных в FWC», сбой — «не прочитано» и предупреждение.
- Отсутствие записи не доказывает отсутствие Range в проекте. Range — свойства тега, Excel не меняется; в Limits I/O field только цвета.
- «Сводка» — пары «подпись — значение»; без данных ПЛК — «Данные ПЛК: не задан».
- Раздел не построен: в дереве ⚠, вместо таблицы «Раздел не построен: <причина>», сообщение на «Ошибках».

## Картинки и сохранение

В галерее имена файлов (`PICTURE_5.png`, как в `images.zip`), первая выбрана; свойства — Name, Table, Number, Format, Bytes, Width, Height и превью.
Двойной щелчок по картинке или щелчок в её свойствах — на всё окно; ←/→ — соседняя, Esc, фон или ✕ — закрыть.
- «Экспортировать все данные»: «Вся книга…» и «Текущий лист…» → `panel_data.xlsx`; «Экспорт всех текстов…» → `PDATA.xlsx`.
- «Экспорт всех картинок»: «Выбранная картинка…» — как есть, «Все в zip…» — `images.zip`, файлы `PICTURE_<n>.png`.
- «Сохранить как» помнит папку, сначала открывает папку `pdata.fwc`; отмена не меняет файлы, сбой не портит прежний файл.
- В экспорте показанные данные со всеми языками, «Теги» и без тегов; листа «Ошибки» нет, непостроенные разделы пропускаются и названы в уведомлении.
- Итог — «Сохранено» и путь с переносами; ошибка записи также в строке состояния.

## Info и ошибки

Info — моноширинный текст чтения без предупреждений/ошибок: файл, TOC, числа, стартовый экран и `Файл ПЛК: …` при выбранных данных ПЛК.
«Ошибки» — жёлтые предупреждения ⚠, красные ошибки ⛔ и непостроенные разделы. Заголовок показывает иконку/число по худшему уровню; при нуле скрывает их.
После открытия с проблемами на 6 с появляется уведомление справа сверху: «Есть ошибки» или «Есть предупреждения», `N — вкладка «Ошибки»`; вкладка не переключается.
Строка состояния — путь, «Строк: N из M» таблицы, «Экранов: N», «Предупреждений и ошибок: N (вкладка «Ошибки»)».
Ошибка действия красная («Не удалось сохранить: …», «Строка не скопирована: …» при занятом буфере). Сбрасывается выбором узла/строки/картинки, открытием или удачным сохранением.
Длинные путь и ошибка — с многоточием, целиком в подсказке.

## Ограничения

У объектов без подробных свойств показаны рамка, имя, таблица и положение. Имя стиля I/O field и шаблон экрана не извлекаются. Анимации и события объектов доступны в описанном для I/O field объёме.
Событий экранов в Excel и тексте чтения, листа «Ошибки», hex-выгрузки и редактирования `pdata.fwc` нет.
