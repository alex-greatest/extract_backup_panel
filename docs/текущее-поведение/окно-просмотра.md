# Окно просмотра

Окно показывает экраны панели из `pdata.fwc`: дерево проекта, экран в его
размере и свойства экрана. Только просмотр: данные ПЛК и файлы рядом с
`pdata.fwc` не читаются, файлы не пишутся. Нужны Windows и WebView2.

Запуск из корня репозитория: `dotnet run --project src/FlexRt.Ui`.

## Открыть панель

- Кнопка «Открыть pdata.fwc…» — стандартный диалог Windows, фильтр `*.fwc` и
  «Все файлы» (шаговые копии с другим именем). Отмена ничего не меняет.
- Во время чтения кнопка занята («Чтение…»), в дереве — «Чтение файла…», в
  строке состояния — «Чтение <путь>…». Прежняя панель убирается сразу.
- Файл не читается — в строке состояния «Файл не прочитан: <причина>», в
  дереве снова «Откройте pdata.fwc».
- После чтения выбран стартовый экран, а если его нет — первый.
- До первого открытия: в дереве «Откройте pdata.fwc», в строке состояния
  «Файл не открыт».

## Дерево проекта

Как в TIA:

- корень — имя открытого файла;
- `Screens` — обычные экраны;
- `Screen management` → `Pop-up screens`, `Slide-in screens` и `Permanent
  area` (прямо в `Screen management`, без своей папки);
- `Вид не опознан` — экраны, вид которых не определился (`?` на листе
  «Экраны»).

Пустые папки не показываются. Стартовый экран помечен `▶`. Порядок экранов —
как на листе «Экраны»: Permanent area, экраны по номеру, остальные в порядке
файла. Щелчок по экрану показывает его на холсте и в свойствах; щелчок по
папке или корню только подсвечивает узел, холст и свойства остаются прежними.

## Холст

- Заголовок — путь как в TIA: `pdata.fwc ▸ <вид> ▸ <имя>`.
- Экран — пустой прямоугольник его размера: объекты не рисуются.
- Внизу — размер в пикселях (`800 × 480 px`) и масштаб 25, 50, 75, 100, 125,
  150, 200 % (по умолчанию 100 %).
- Экран не выбран — «Выберите экран в дереве проекта».

## Свойства

- Заголовок — `<имя> [<вид>]`, справа вкладки Properties и Info; у Info —
  число предупреждений разбора.
- Properties — внутренние вкладки Properties, Animations, Events.
- Properties: слева группы, справа поля выбранной группы, только чтение.
  Значения — те же, что в строке экрана на листе «Экраны»:
  - General — Name, Number, Start screen (флажок), Вид;
  - Layout — Width, Height.
- Animations и Events — «не разобрано — в pdata.fwc пока не найдено.»
- Info — предупреждения разбора панели, те же, что печатает консоль; нет —
  «Предупреждений разбора нет».

## Строка состояния

- Путь открытого файла.
- `Экранов: N` — как в консоли: только экраны вида `Screen`.
- «Предупреждений разбора: N (вкладка Info)», если они есть.

## Чего нет

- Объектов на экранах, шаблона экрана, анимаций и событий.
- Тегов, алармов, системных событий, классов и групп алармов, картинок,
  «Сводки», данных ПЛК.
- Выгрузки в файлы: `panel_data.xlsx`, `PDATA.xlsx`, `pdata`, `images` и лог
  делает только консольная программа.
- Правки: окно ничего не меняет в `pdata.fwc`.
