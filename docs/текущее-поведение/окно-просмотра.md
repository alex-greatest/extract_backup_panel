# Окно просмотра

Окно показывает панель из `pdata.fwc`: дерево проекта, экран в его размере,
таблицы листов `panel_data.xlsx` и `PDATA.xlsx` и свойства выбранного. Только
просмотр: данные ПЛК и файлы рядом с `pdata.fwc` не читаются, файлы не
пишутся. Нужны Windows и WebView2.

Запуск из корня репозитория: `dotnet run --project src/FlexRt.Ui`.

## Открыть панель

- Кнопка «Открыть pdata.fwc…» — стандартный диалог Windows, фильтр `*.fwc` и
  «Все файлы». Отмена ничего не меняет.
- Во время чтения кнопка занята («Чтение…»), прежняя панель убирается сразу.
- Файл не читается — в строке состояния «Файл не прочитан: <причина>».
- После чтения выбран стартовый экран, а если его нет — первый.

## Дерево проекта

- корень — имя файла; «Сводка»; HMI tags;
- HMI alarms → Discrete alarms, Analog alarms, System events, Alarm classes,
  Alarm groups — только разделы, чьи листы есть в книге;
- Screens — обычные экраны; щелчок по папке — таблица листа «Экраны»;
- Screen management → Pop-up screens, Slide-in screens, Permanent area;
- «Вид не опознан» — экраны вида `?`; «Тексты» → по разделу на язык.

Справа от раздела — число строк его таблицы, у Screens — строк листа
«Экраны». Стартовый экран помечен `▶`. Щелчок по экрану или разделу показывает
его; по другой папке или корню только подсвечивает узел.

## Экран

- Заголовок — `pdata.fwc ▸ <вид> ▸ <имя>`; экран — пустой прямоугольник его
  размера, масштаб 25–200 %.
- Свойства: General — Name, Number, Start screen (флажок), Вид; Layout —
  Width, Height. Animations и Events — «не разобрано».

## Раздел

- Заголовок — `pdata.fwc ▸ HMI alarms ▸ Discrete alarms`.
- Таблица — те же колонки и строки, что на листе, без данных ПЛК: колонки ПЛК
  тегов — «неизвестно». Над HMI tags — статистика, как вверху листа «Теги».
- Сортировка щелчком по заголовку, фильтр под заголовком: в тексте — «содержит»
  без учёта регистра, в числах — «равно». Ширину колонок можно менять.
- Первая строка выбрана сразу; в свойствах — все ячейки строки под
  заголовками колонок. Фильтр скрыл выбранную строку — выбор снимается.
- Ctrl+C — выбранная строка в буфер через Tab.
- «Сводка» — список «подпись — значение», как на листе; модель панели и
  версия Runtime — «неизвестно», «Данные ПЛК» — «не задан».
- Ядро не смогло построить таблицу — у раздела в дереве ⚠, вместо таблицы
  «Раздел не построен: <причина>», то же на вкладке Info.

## Info и строка состояния

- Info — предупреждения разбора, как в консоли, и разделы, которые не
  построены; число — на вкладке.
- Строка состояния: путь, «Строк: N из M» у таблицы, `Экранов: N` (как в
  консоли), «Предупреждений разбора: N (вкладка Info)», «Строка не
  скопирована: …», если буфер занят.

## Чего нет

- Объектов на экранах, шаблона экрана, анимаций и событий.
- Данных ПЛК, листа «Ошибки», картинок.
- Выгрузки в файлы: её делает только консольная программа.
- Правки: окно ничего не меняет в `pdata.fwc`.
