# Запуск и результаты

Программа читает скомпилированную конфигурацию панели из TIA Portal
(`pdata.fwc`) и, если есть, данные ПЛК: проект (`PEData.plf`) или копию карты
памяти ПЛК. Извлекает теги, системные события, дискретные и аналоговые алармы,
классы алармов и строки языков, все таблицы сохраняет в hex. Проверено: TIA V17 и V21, панели TP700,
TP1500, TP1900 Comfort, S7-1500 и S7-1200; карта — одна, S7-1500F (TIA V19).

## Что нужно сделать

Скомпилируйте проект в TIA. Пути к `pdata.fwc` (папка `Generates`), к
`System\PEData.plf` и выходные пути заданы в начале `src\FlexRt\Program.cs`,
аргументов нет. Запуск из корня репозитория: `dotnet run --project src/FlexRt`.

Переменные окружения разово подменяют входы: `FLEXRT_INPUT` — `pdata.fwc`,
`FLEXRT_PLC` — `PEData.plf` (исходный или выгруженный из ПЛК; можно читать,
пока он открыт в TIA) или папку карты ПЛК с `SIMATIC.S7S`. `FLEXRT_OUT`
подменяет каталог результата `data\out`, имена файлов те же. Пустая
переменная не действует.

## Какие файлы получаются

`panel_data.xlsx`:

- «Сводка» — модель панели и версия Runtime (файлы рядом с `pdata.fwc`), IP
  панели, числа тегов, событий, алармов и классов, соединения и IP ПЛК,
  источник данных ПЛК, имя и модель CPU (с карты), число тегов ПЛК и DB.
- «Теги» — статистика (всего, внутренних, с ПЛК, найдено, нет в ПЛК,
  неизвестно, с абсолютной адресацией), затем таблица как HMI tags в TIA без
  Comment и Logged-данных. Соединение, режим доступа, цикл и адрес абсолютного
  тега — из панели; тип, PLC name, PLC tag (`DB.член.член`) и Source comment —
  из данных ПЛК, без них «неизвестно»; символьного тега нет в ПЛК —
  «отсутствует в файле ПЛК»; абсолютный без тега ПЛК — PLC tag — имя DB
  (`AlarmsDB`) или пусто. Внутренний тег — Connection `<Internal tag>`.
- «Системные события» — ID и текст на каждом языке, как System events в TIA.
- «Дискретные алармы» — как Discrete alarms в TIA, но без имени аларма (его нет
  ни в панели, ни в ПЛК): ID, текст на каждом языке с полями
  (`<Tag : 6, имя тега>`, `<Text list, ?>`), класс (свой — Display name), тег,
  бит и адрес срабатывания и квитирования HMI, тег и бит квитирования PLC,
  Report. Адрес символьного тега — из данных ПЛК, без них «неизвестно».
- «Аналоговые алармы» — как Analog alarms в TIA без имени аларма: ID, текст на
  каждом языке, класс, тег срабатывания, Limit (число, `12.5` или имя тега),
  Limit mode, Report. Всё из панели, данные ПЛК не нужны.
- «Классы алармов» — как Alarm classes в TIA: ID, Display name по языкам, Name
  (свой — `?`), State machine, Log (`<No log>`), E-mail, 4 цвета `R, G, B` с
  заливкой (цвета выключены в Runtime settings — «цвета классов выключены»),
  тексты состояний по языкам. Журнал или письма не прочитаны — Log, E-mail `?`.
- «Ошибки» — если данные ПЛК сломаны или в них неразобранные объекты.

`PDATA.xlsx` — лист на язык (`0x409`), колонки `idx` и `str`. В обоих Excel
текст длиннее 32767 символов обрезается, апостроф в начале сохраняется.

`logs\flexrt-<дата>.log` — пути, сводки, предупреждения, сопоставление, время
экспортов, ошибки со стеком; файл на день, хранятся последние 14.

Папка `pdata` — по папке `0x<номер>_<имя>` на таблицу: `header.hex.txt` и файл
на элемент или `raw.hex.txt`. Перед записью папка удаляется.

## Сообщения и код возврата

- Файл панели не читается — `Не удалось прочитать ...`, код 1.
- Незнакомая запись таблицы не обрывает разбор: одно
  `ПРЕДУПРЕЖДЕНИЕ: не разобрано - <таблица>: ...` на таблицу.
- Нет файла ПЛК — `Файл ПЛК: ... не найден - данные ПЛК: неизвестно`, не
  ошибка. Данные ПЛК сломаны — `ПРЕДУПРЕЖДЕНИЕ: файл ПЛК - ...` и лист «Ошибки»;
  непредвиденная ошибка — «непредвиденная ошибка <тип>: …», стек в логе. Данные
  панели всё равно выгружаются.
- Ошибка одного экспорта — `[<экспорт>] ОШИБКА: ...`, остальные выполняются.
  Нет тегов или строк — Excel пропускается, старый файл удаляется.

Код `0` — без предупреждений и ошибок, иначе `1`.

## Ограничения

- Панель с несколькими соединениями вместе с данными ПЛК не поддерживается:
  `ОШИБКА: не поддерживается: ...`, код 1, файлы не создаются.
- Не проверены: ПЛК кроме S7-1500/S7-1200, несколько панелей, комментарии ПЛК
  на нескольких языках. Алармы сверены с TIA на одном проекте (A603A0097).
