# Запуск и результаты

Программа читает скомпилированную конфигурацию панели из TIA Portal
(`pdata.fwc`) и, если есть, данные ПЛК: проект (`PEData.plf`) или копию карты
памяти ПЛК. Она извлекает теги со связью с ПЛК и строки языков, а все таблицы
панели сохраняет в hex-виде. Проверено на TIA Portal V17 и V21, панель TP700
Comfort, ПЛК S7-1500 и S7-1200; карта — одна, S7-1500F (TIA V19) с панелью TP1500.

## Что нужно сделать

Скомпилируйте проект в TIA. Пути к `pdata.fwc` (папка `Generates`), к
`System\PEData.plf` проекта ПЛК и выходные пути заданы в начале
`src\FlexRt\Program.cs`, аргументов нет. Запуск из корня репозитория:

```
dotnet run --project src/FlexRt
```

Переменные окружения разово подменяют входные файлы: `FLEXRT_INPUT` —
`pdata.fwc`, `FLEXRT_PLC` — `PEData.plf`. Проект ПЛК может быть исходным или
выгруженным из ПЛК (Upload); его можно читать, пока он открыт в TIA. Если путь
ПЛК — папка, это копия карты ПЛК: в ней должна лежать `SIMATIC.S7S`.
`FLEXRT_OUT` разово подменяет каталог результата `data\out`: `PDATA.xlsx`,
`panel_data.xlsx`, папки `pdata` и `logs` пишутся туда с теми же именами.
Пустая или не заданная переменная не действует.

## Что видно в консоли

```
Файл:    samples/pdata.fwc (107372 байт)
Таблиц:  67
  0x1    VAR                      элементов: 16     offset: 0x98 size: 768
  ...
Строк языков: 625
Тегов: 16

Файл ПЛК: ...\CCB-A03 (карта ПЛК; ПЛК: 1, тегов ПЛК: 591)   — если путь ПЛК — карта

[Теги -> XLSX] 16 тегов -> ...\data\out\panel_data.xlsx
[Explode -> HEX] 264 файлов -> ...\data\out\pdata
```

## Какие файлы получаются

`panel_data.xlsx`, первый лист «Сводка» — модель панели, версия Runtime (из
файлов рядом с `pdata.fwc`), IP панели, соединения и IP ПЛК, источник данных
ПЛК, имя и модель CPU (с карты), число тегов ПЛК и DB. Лист «Теги» — сверху
статистика (всего, внутренних, с ПЛК, найдено, есть в панели — нет в ПЛК,
неизвестно, с абсолютной адресацией), две пустые строки, затем таблица с
колонками как в HMI tags в TIA (без Comment). Строки — в порядке файла.

- Внутренний тег: Connection `<Internal tag>`, колонки ПЛК пустые.
- PLC-тег: соединение, режим доступа и цикл (`100 ms`, `1 s`) — из панели;
  адрес — только при абсолютном доступе (`%IW44`, `%DB80.DBW0`); тип, PLC
  name, PLC tag (у членов DB — путь `DB.член.член`) и Source comment — из
  проекта ПЛК или карты; с карты PLC name — имя папки карты. Без проекта ПЛК тип — по коду из панели (`USInt/Char`,
  `DInt/Time`, если различить нельзя), колонки ПЛК — «неизвестно».
- Символьный тег, которого нет в проекте ПЛК, — «отсутствует в файле ПЛК».
  Абсолютный тег без тега ПЛК — имя ПЛК есть, PLC tag — имя DB для адреса в DB
  (`AlarmsDB`), иначе пустой.
- Logged пустой: в файлах его нет. Колонки Comment нет — этих данных нигде нет.

Лист «Ошибки» появляется, если проект ПЛК сломан или в нём есть
неразобранные объекты.

`PDATA.xlsx` — лист на каждый язык (`0x409`), колонки `idx` и `str`. Текст
длиннее 32767 символов обрезается, в обоих файлах Excel.

`logs\flexrt-<дата>.log` — лог запуска: пути, сводки, предупреждения, итог
сопоставления, время экспортов, ошибки со стеком вызовов. Файл на день,
хранятся последние 14.

Папка `pdata` — по папке `0x<номер>_<имя>` на таблицу: `header.hex.txt` и
файл на элемент или `raw.hex.txt` целиком. Перед записью папка удаляется.

## Сообщения и код возврата

- Файл панели не читается — `Не удалось прочитать ...`, код 1.
- Незнакомая запись или элемент таблицы не обрывают разбор: одно сводное
  `ПРЕДУПРЕЖДЕНИЕ: не разобрано - <таблица>: ...` на таблицу.
- Нет файла ПЛК — `Файл ПЛК: ... не найден - данные ПЛК: неизвестно`, это не
  ошибка. Файл ПЛК сломан (контрольная сумма, обрыв) или в папке карты нет
  `SIMATIC.S7S\OMSSTORE`, или сжатые данные карты не распаковываются —
  `ПРЕДУПРЕЖДЕНИЕ: файл ПЛК - ...` и лист «Ошибки».
- Непредвиденная ошибка при чтении проекта ПЛК — «непредвиденная ошибка
  <тип>: …» на листе «Ошибки», подробности — в логе; данные панели выгружаются.
- Ошибка одного экспорта — `[<экспорт>] ОШИБКА: ...`, остальные выполняются.
  Нет тегов или строк — Excel пропускается, его старый файл удаляется.

Код `0` — без предупреждений и ошибок. Код `1` — ошибка чтения,
предупреждение разбора, проблема файла ПЛК, `raw.hex.txt` или ошибка экспорта.

## Ограничения

- Панель с несколькими соединениями и данными ПЛК (файл или карта) пока не
  поддерживается: `ОШИБКА: не поддерживается: …`, код 1, файлы не создаются.
- Не проверены: ПЛК кроме S7-1500/S7-1200, несколько панелей, комментарии ПЛК
  на нескольких языках (берётся первый непустой).
