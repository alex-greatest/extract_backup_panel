# Запуск и результаты

Программа читает скомпилированную конфигурацию панели из TIA Portal
(`pdata.fwc`) и, если выбраны, данные ПЛК: проект (`PEData.plf`) или копию карты
памяти ПЛК. Извлекает теги, системные события, дискретные и аналоговые алармы,
классы и группы алармов, экраны, картинки, строки языков. Проверено:
TIA V17 и V21, TP700, TP1500, TP1900 Comfort, S7-1500 и S7-1200; карты — две: реальная
S7-1500F (TIA V19) и тестовая (V21). Кнопки, дерево и вкладки окна — [окно-просмотра.md](окно-просмотра.md).

## Что нужно сделать

Скомпилируйте проект в TIA. Запуск из корня репозитория:
`dotnet run --project src/FlexRt.Ui` (нужны Windows и WebView2). В окне —
«Открыть pdata.fwc…» (файл из папки `Generates` проекта или из бэкапа панели),
по желанию «Данные ПЛК» — `PEData.plf` (исходный или выгруженный из ПЛК, можно
открытый в TIA) или папка карты ПЛК с `SIMATIC.S7S`. Консольной программы,
аргументов и переменных окружения нет.

## Текст чтения

Вкладка Info — основной текст, вкладка «Ошибки» — предупреждения и ошибки:

```
Файл:    samples/pdata.fwc (107372 байт)
Таблиц:  67
  0x1    VAR                      элементов: 16     offset: 0x98 size: 768
Строк языков: 625
Тегов: 16
...
Стартовый экран: Root screen (1)
Картинок: 12
Файл ПЛК: ...\System\PEData.plf (ПЛК: 2, тегов ПЛК: 51)
```

С картой ПЛК: `Файл ПЛК: ...\CCB-A03 (карта ПЛК; ПЛК: 1, тегов ПЛК: 591)`.

## Что сохраняется

Файлы пишутся только по кнопкам, диалогом «Сохранить как». `panel_data.xlsx` —
вся книга или один лист:

- «Сводка» — IP панели, числа из текста выше, стартовый
  экран, соединения и IP ПЛК, источник данных ПЛК, имя и модель CPU, теги ПЛК и
  DB.
- «Теги» — статистика, затем таблица как HMI tags в TIA без Comment и Logged.
  Соединение, доступ, цикл, абсолютный адрес — из панели; тип, PLC name, PLC tag
  и Source comment — из данных ПЛК (нет данных — «неизвестно», нет тега —
  «отсутствует в файле ПЛК»). Внутренний тег — Connection `<Internal tag>`.
- «Системные события» — ID и текст на каждом языке, как System events в TIA.
- «Дискретные алармы» — как Discrete alarms в TIA без имени аларма: ID, тексты
  с полями (`<Tag : 6, имя тега>`), класс, группа, теги, биты и адреса
  срабатывания и квитирования, Report; адрес символьного тега — из данных ПЛК.
- «Аналоговые алармы» — как Analog alarms в TIA без имени аларма: ID, текст на
  каждом языке, класс, группа, тег срабатывания, Limit (число, `12.5` или имя тега),
  Limit mode, Report. Всё из панели, данные ПЛК не нужны.
- «Классы алармов» — как Alarm classes в TIA: ID, Display name, Name (свой — `?`),
  State machine, Log, E-mail, 4 цвета `R, G, B` с заливкой, тексты состояний.
- «Группы алармов» — ID групп, назначенных алармам, и число алармов каждого
  вида; имени группы в панели нет.
- «Экраны» — имя, номер, стартовый, ширина, высота, цвет фона `R, G, B` с заливкой, подсказка (Tooltip) на
  каждом языке как есть, вид экрана; без шаблона.

Листа с ошибками нет: предупреждения и ошибки — только на вкладке «Ошибки».

`PDATA.xlsx` — лист на язык (`0x409`), колонки `idx` и `str`; строк нет — файл не
пишется. В обоих Excel текст длиннее 32767 символов обрезается, апостроф в начале сохраняется.

Картинки (PNG, JPEG) — выбранная файлом как есть или все архивом `images.zip`:
`PICTURE_<n>.png`, `TILED_PICTURE_<n>.png`, без привязки к экранам.

## Сообщения

- Файл панели не читается — `Не удалось прочитать ...`, панель не открывается.
- Незнакомая запись таблицы не обрывает разбор: одно предупреждение на таблицу,
  `ПРЕДУПРЕЖДЕНИЕ: не разобрано - <таблица> @ 0x<смещение>: ...`.
- Нет файла ПЛК — `Файл ПЛК: ... не найден`, не ошибка. Данные ПЛК сломаны —
  `Файл ПЛК: ... не прочитан` и `ПРЕДУПРЕЖДЕНИЕ: файл ПЛК - ...`; колонки
  ПЛК — «неизвестно». Неразобранный объект ПЛК — то же предупреждение.
- Ошибка сохранения — уведомление и строка состояния «Не удалось сохранить: …»;
  прежний файл не портится.

## Ограничения

- Панель с несколькими соединениями вместе с данными ПЛК не поддерживается:
  `ОШИБКА: не поддерживается: ...; панель показана без данных ПЛК`.
- Не проверены: ПЛК кроме S7-1500/S7-1200, несколько панелей, комментарии ПЛК
  на нескольких языках. Алармы сверены с TIA на A603A0097, группы — на Project1.
