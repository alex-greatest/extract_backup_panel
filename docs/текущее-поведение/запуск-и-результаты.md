# Запуск и результаты

Программа читает скомпилированную конфигурацию панели из TIA Portal
(`pdata.fwc`) и, если есть, данные ПЛК: проект (`PEData.plf`) или копию карты
памяти ПЛК. Извлекает теги, системные события, дискретные и аналоговые алармы,
классы и группы алармов, экраны, картинки, строки языков, все таблицы — в hex. Проверено:
TIA V17 и V21, TP700, TP1500, TP1900 Comfort, S7-1500 и S7-1200; карты — две: реальная
S7-1500F (TIA V19) и тестовая (V21). Окно просмотра — [окно-просмотра.md](окно-просмотра.md).

## Что нужно сделать

Скомпилируйте проект в TIA. Пути к `pdata.fwc` (папка `Generates`), к
`System\PEData.plf` и выходные пути заданы в начале `src\FlexRt\Program.cs`,
аргументов нет. Запуск из корня репозитория: `dotnet run --project src/FlexRt`.

Переменные окружения разово подменяют входы: `FLEXRT_INPUT` — `pdata.fwc`,
`FLEXRT_PLC` — `PEData.plf` (исходный или выгруженный из ПЛК, можно открытый в
TIA) или папку карты ПЛК с `SIMATIC.S7S`; `FLEXRT_OUT` — каталог `data\out`,
имена файлов и папок те же. Пустая переменная не действует.

## Какие файлы получаются

`panel_data.xlsx`:

- «Сводка» — модель, Runtime и IP панели, числа строк консоли выше, стартовый
  экран, соединения и IP ПЛК, источник данных ПЛК, имя и модель CPU, теги ПЛК и DB.
- «Теги» — статистика, затем таблица как HMI tags в TIA без Comment и Logged.
  Соединение, доступ, цикл, абсолютный адрес — из панели; тип, PLC name, PLC tag
  и Source comment — из данных ПЛК (нет данных — «неизвестно», нет тега —
  «отсутствует в файле ПЛК»). Внутренний тег — Connection `<Internal tag>`.
- «Системные события» — ID и текст на каждом языке, как System events в TIA.
- «Дискретные алармы» — как Discrete alarms в TIA без имени аларма: ID, тексты
  с полями (`<Tag : 6, имя тега>`), класс, группа, теги, биты и адреса
  срабатывания и квитирования, Report; адрес символьного тега — из данных ПЛК.
- «Аналоговые алармы» — как Analog alarms в TIA без имени аларма: ID, текст на
  каждом языке, класс, группа, тег срабатывания, Limit (число, `12.5` или имя тега),
  Limit mode, Report. Всё из панели, данные ПЛК не нужны.
- «Классы алармов» — как Alarm classes в TIA: ID, Display name, Name (свой — `?`),
  State machine, Log, E-mail, 4 цвета `R, G, B` с заливкой, тексты состояний.
- «Группы алармов» — ID групп, назначенных алармам, и число алармов каждого
  вида; имени группы в панели нет.
- «Экраны» — имя, номер, стартовый, ширина, высота, вид экрана; без шаблона.
- «Ошибки» — если данные ПЛК сломаны или в них неразобранные объекты.

`PDATA.xlsx` — лист на язык (`0x409`), колонки `idx` и `str`. В обоих Excel текст длиннее 32767 символов обрезается, апостроф в начале сохраняется.

`logs\flexrt-<дата>.log` — пути, сводки, предупреждения, сопоставление, время
экспортов, ошибки со стеком; файл на день, хранятся последние 14.

Папка `pdata` — по папке `0x<номер>_<имя>` на таблицу: `header.hex.txt`, файл на элемент или `raw.hex.txt`; перед записью удаляется.

Папка `images` — все картинки бэкапа (PNG, JPEG) файлами `PICTURE_<n>.png`,
`TILED_PICTURE_<n>.png`, без привязки к экранам; перед записью удаляется.

## Сообщения и код возврата

- Файл панели не читается — `Не удалось прочитать ...`, код 1.
- Незнакомая запись таблицы не обрывает разбор: одно предупреждение на таблицу,
  `ПРЕДУПРЕЖДЕНИЕ: не разобрано - <таблица> @ 0x<смещение>: ...`.
- Нет файла ПЛК — `Файл ПЛК: ... не найден`, не ошибка. Данные ПЛК сломаны —
  `Файл ПЛК: ... не прочитан`, `ПРЕДУПРЕЖДЕНИЕ: файл ПЛК - ...` и лист «Ошибки»,
  стек в логе; панель выгружается.
- Ошибка одного экспорта — `[<экспорт>] ОШИБКА: ...`, остальные выполняются.
  Нет тегов или строк — Excel пропускается, старый файл удаляется. Код `0` —
  без предупреждений и ошибок, иначе `1`.

## Ограничения

- Панель с несколькими соединениями вместе с данными ПЛК не поддерживается:
  `ОШИБКА: не поддерживается: ...`, код 1, файлы и папки не создаются.
- Не проверены: ПЛК кроме S7-1500/S7-1200, несколько панелей, комментарии ПЛК
  на нескольких языках. Алармы сверены с TIA на A603A0097, группы — на Project1.
