# Запуск и результаты

Текущая версия читает `PDATA.FWX`, извлекает строки языков из
`STRINGSTORE` и сохраняет все таблицы TOC в текстовом hex-виде. Семантические
данные тегов программа сейчас не извлекает.

## Что нужно сделать

Положите файл панели в `data\PDATA.fwx`. Аргументов командной строки нет:
входной файл, книга XLSX и каталог hex-файлов заданы в начале
`src\FlexRt\Program.cs`. Запуск из корня репозитория:

```
dotnet run --project src/FlexRt
```

## Что видно в консоли

Для синтетического `samples\sample.fwx`, скопированного в
`data\PDATA.fwx`, подтверждён такой вывод:

```
Файл:    D:\projects\extract_backup\data\PDATA.fwx (674 байт)
Таблиц:  5
  0x1    VAR                      элементов: 2      offset: 0x40 size: 156
  0x2    DATALINK_READWR          элементов: 2      offset: 0xdc size: 156
  0x3    STRINGSTORE              элементов: 1      offset: 0x178 size: 170
  0x4    WEBLINK                  элементов: 0      offset: 0x222 size: 52
  0x5    FUNC_STARTPROC           элементов: 0      offset: 0x256 size: 52
Строк языков: 6
[Языки -> XLSX] 2 языков, 6 строк -> D:\projects\extract_backup\data\out\PDATA.xlsx
[Explode -> HEX] 10 файлов -> D:\projects\extract_backup\data\out\pdata
```

Строка таблицы содержит её номер, имя, число элементов, смещение от начала
файла и размер. Имена таблиц приходят из самого FWX.

## Какие файлы получаются

`PDATA.xlsx` содержит лист на каждый LCID, с именами вида `0x409`. На листе
есть колонки `idx` и `str`; текст записывается как текст, а значение длиннее
32767 символов обрезается.

Папка `pdata` содержит отдельную папку для каждой таблицы TOC, включая `VAR`
и `DATALINK_READWR`. Внутри лежат `header.hex.txt` и hex-файл на каждый
элемент с именем `<номер>_<всего>.hex.txt`. Если таблица не подходит под
раскладку каталога смещений, создаётся один `raw.hex.txt` со всеми её байтами.

Старый `data\out\tags.html` сохранён как прежний артефакт, но текущий запуск
его не создаёт и не обновляет. `samples\expected\tags.html` также сохранён;
он не является текущим результатом экспорта.

## Сообщения и код возврата

Предупреждение о сбое разбора сообщает таблицу и смещение. Записи, прочитанные
до сбоя `STRINGSTORE`, остаются в XLSX. Если таблица не подходит под hex-
раскладку, выводится предупреждение о сохранении `raw.hex.txt`; остальные
таблицы обрабатываются.

Ошибка одного экспорта выводится как `[Языки -> XLSX] ОШИБКА: ...` или
`[Explode -> HEX] ОШИБКА: ...`. Экспорты независимы. Если в `STRINGSTORE` нет
строк, XLSX пропускается сообщением `в STRINGSTORE нет строк, пропуск`.

Код возврата `0` означает отсутствие предупреждений и ошибок экспортов. Код
`1` означает ошибку чтения, предупреждение разбора, сохранение таблицы как
`raw.hex.txt` или ошибку экспорта. Для `samples\bad.fwx` подтверждено понятное
сообщение без stack trace и код `1`.

## Ограничения

`VAR` и `DATALINK_READWR` сейчас доступны в каталоге `pdata` как hex-байты,
но их имена, адреса, типы и циклы опроса семантически не извлекаются. HTML-
экспорт удалён. Проверки на настоящем `PDATA.FWX` пока нет: приведённые числа
и результаты подтверждены только синтетическим файлом из `samples\`.
