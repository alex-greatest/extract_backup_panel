# Оформление кнопок

FlexRt читает оформление кнопок из записей `VIEW_BUTTONS` и
`VIEW_STATEBUTTO`. Ниже описана раскладка, подтверждённая на контрольных
файлах TP700 Comfort, скомпилированных TIA Portal V21 Update 1.

## Ссылки объекта

Установлено по контрольным файлам и сверено с чтением `FwdButtonLean`
компонентом Siemens. Смещения отсчитываются от конца ссылок именованного
объекта. Числа и пары ссылок записаны в little-endian.

| Смещение | Поле |
| --- | --- |
| `+0x14` | Размер блока `0x3d`, u32 |
| `+0x18` | Начало блока, версия потока `0x8000000a`, u32 |
| `+0x28` | `PictureAutoSizing`, u32. `0` — исходный размер, `1` — растянуть картинку |
| `+0x31` | Четыре ссылки Normal |
| `+0x41` | Четыре ссылки Pressed |
| `+0x51` | Ссылка на `PS_Focus` |

В каждом наборе четыре пары u16: Id таблицы и индекс элемента.
Первые три ссылаются на `PS_BorderedShap`, `PS_Text` и `PS_Fill_Color`,
четвёртая — на `PS_Position`. Пара `0, 0xffff` означает отсутствие
компонента. FlexRt читает все четыре ссылки каждого состояния и отдельно
ссылку на `PS_Focus`. За меткой конца подписей `0x9ffffe00` ссылка на
`FONT` записана в порядке «индекс элемента, Id таблицы».

Назначение Normal и Pressed установлено по чтению Siemens. В контрольных
записях сами параметры оформления совпадали, даже когда индексы различались.

## Записи стилей

Установлено по байтам и шаговым компиляциям. Смещения ниже отсчитываются
от начала записи соответствующей таблицы.

| Таблица | Смещение | Поле |
| --- | --- | --- |
| `PS_BorderedShap` | `+0x14`, `+0x16` | Код линии и ширина, u16 |
| `PS_BorderedShap` | `+0x18`, `+0x1c` | RGB линии и фона рамки |
| `PS_BorderedShap` | `+0x20` | Первый радиус угла, u16 |
| `PS_BorderedShap` | `+0x2c` | Ссылка на `TILED_PICTURE` |
| `PS_BorderedShap` | `+0x34`, `+0x44` | Первый и второй переходы градиента |
| `PS_Fill_Color` | `+0x14` | RGB заливки или среднего цвета градиента |
| `PS_Fill_Color` | `+0x17` | Признак прозрачности: `00` — непрозрачно, `ff` — прозрачно |
| `PS_Position` | `+0x14`–`+0x17` | Отступы картинки (пкс), по одному байту в порядке Top, Bottom, Left, Right |
| `PS_Position` | `+0x1c` | Выравнивание картинки по горизонтали, u8. `0` — Right, `1` — Center, `2` — Left |
| `PS_Position` | `+0x1d` | Выравнивание картинки по вертикали, u8. `0` — Top, `1` — Middle, `2` — Bottom |
| `PS_Focus` | `+0x14` | R, G, B рамки фокуса |
| `PS_Focus` | `+0x18` | Ширина рамки фокуса в пикселях, u16 |
| `TILED_PICTURE` | `+0x10`, `+0x12` | Ширина и высота, u16 |
| `TILED_PICTURE` | `+0x14`–`+0x1a` | Границы растягивания Left, Top, Right, Bottom, четыре u16 |
| `TILED_PICTURE` | `+0x1c`, `+0x20` | Длина картинки, u32, и начало её байтов |

В записи перехода направление стоит на `+0x00` (0 — горизонтальное,
1 — вертикальное), ширина в пикселях — на `+0x02`, крайний RGB — на
`+0x08`. Ссылку на картинку и переходы FlexRt читает только у записи
`PS_BorderedShap` длиной `0x50`. Для другой длины читает общую часть
рамки. Форматы текста и шрифтов описаны в [стилях объектов](стили-объектов.md).

Раскладка `PS_Focus` установлена на пяти шаговых компиляциях обычной кнопки
и кнопки с нажатым состоянием. Запись занимала 28 байт. Цвет сохранялся при
ширине 0. Тип ширины подтверждён сериализатором Siemens (`BinWord`).
FlexRt показывает оба значения в **Design → Focus**. При повреждённой ссылке
инспектор показывает «Не разобрано», а вкладка «Ошибки» сообщает таблицу и
смещение. Результаты находятся в `data/real/button-design-20261118/`.

## Layout

Шаговые компиляции `data/real/button-layout-20261123/` подтверждают
`PictureAutoSizing`, поля и выравнивание картинки в `PS_Position` и поля
текста в `PS_Text` на `+0x1c`–`+0x1f` (Top, Bottom, Left, Right).
Шаг `301_combined_all` подтверждает независимость полей текста и картинки.
Короткая запись `PS_Position` или неизвестный код выравнивания дают
предупреждение с таблицей и смещением. Остальные свойства читаются.

Для **Fit object to contents** поле FWC пока не установлено. В контрольных
компиляциях `A`, `B`, `C` из `data/real/button-fit-geometry/` TIA вернула
`FitToLargest` со значениями `false → true → false`. Размер оставался
96 × 32 пкс, а все 120 байт от конца ссылок записи кнопки совпали.
Инспектор показывает «Не определено по FWC».

## Text format

Семь компиляций из `data/real/button-text-format-20261123/` и повторный
экспорт XML из TIA подтверждают для кнопки раскладку `PS_Text` и
`FONT`, описанную в [стилях объектов](стили-объектов.md).

| Источник | Смещение | Установлено для кнопки |
| --- | --- | --- |
| `PS_Text` | `+0x18` | `0` — Right, `1` — Centered, `2` — Left |
| `PS_Text` | `+0x19` | `0` — Top, `1` — Middle, `2` — Bottom |
| `PS_Text` | `+0x1a` | u16. `0` — Horizontal, `0x010e` — Vertical, left (270°), `0x005a` — Vertical, right (90°) |
| `FONT` | Запись языка | Tahoma 16 Bold и Courier New 20 Bold Italic |

В этих семи файлах значения `PS_Text` совпали для Normal и Pressed.
У отдельного контроля в режиме Graphic есть ссылка `FONT`, а ссылки
`PS_Text` отсутствуют у обоих состояний
(`200_graphic_baseline` из `data/real/button-layout-20261123/`).

## Flashing, Styles/Designs и Miscellaneous

В контрольных компиляциях TP700 Comfort режим **Standard** дал цепочку
ссылок от кнопки через `ADAPTCYCLICCHAN` к `TIMER`. Второе слово ссылки
адаптера на таймер равно 105. Цепочка совпала у обычной, невидимой кнопки
и кнопки с отдельным нажатым состоянием. В проверенном варианте **Advanced**
цепочки нет, поэтому FlexRt показывает **Disabled** (шаги 00–01, 18–19,
25–26 и 28 из `data/real/button-misc-security-20261123/compiled/`).

После переноса кнопки со слоя 0 на слой 4 её запись совпала с базовой.
При включении стиля изменились скомпилированные записи оформления.
В **Styles/Designs** FlexRt показывает «Нет в файле» для **Style/Design
settings** и **Style item appearance** и «Не прочитано» для **Device style**.
В **Miscellaneous** для **Layer** отображается «Нет в файле»
(шаги 05–07 той же серии).

**Tooltip** читается для `VIEW_BUTTONS` по паре из `INFO_HANDLER` и номеру
строки в `STRINGSTORE`. При нескольких парах используется первая.
Текст показывается на выбранном языке, а при выборе «Все языки» — на
первом языке панели. Это проверено на подсказке кнопки шаблона `Exit`.
[Раскладка INFO_HANDLER](таблица-info-handler.md).

## Security

В записях `VIEW_BUTTONS` и `VIEW_STATEBUTTO` флаги окна лежат сразу
после ссылок. Сброшенный бит `0x08000000` означает, что **Allow operator
control** включён. Бит сверили на обычной, невидимой кнопке и кнопке
с отдельным нажатым состоянием.

В контрольных компиляциях TP700 Comfort через TIA V21 кнопка с событием
Release без права ссылалась прямо на `FUNC_POST_CLOSE`. При назначении
права кнопка ссылалась на `SECURITY_MONITO`. Запись `SECURITY_MONITO`
содержала ссылки на `SECURITY_UNIT` и функцию, а сразу за ссылками — номер
права `u32`. Для обычной кнопки сверили `1` (Monitor) и `2` (Operate),
для кнопки с отдельным нажатым состоянием — `1` (Monitor).
У обычной кнопки без действия TIA не записала ссылку на право, заданное
в проекте. Компиляции и экспорт XML лежат в
`data/real/button-misc-security-20261123/compiled/` (шаги 02–04, 18–24 и 25–27).

FlexRt читает номер по той же схеме, что и у I/O field. При отсутствии
ссылки поле **Authorization** пустое. Если запись права повреждена,
FlexRt показывает «Не прочитано» и предупреждение с адресом записи.
Остальные свойства кнопки доступны.

## Границы проверки

Итоговое чтение 43 реальных FWC дало 130 кнопок с Appearance без
предупреждений. Локальные файлы и результаты лежат в
`data/real/button-appearance-20261118/`.

- Solid и Double line получили коды 1 и 2. Dash, Dot, DashDot и DashDotDot
  получили общий код 3, в том числе при смене стиля у тех же объектов.
  Исходный пунктир по этим файлам не определяется.
- Выключенный переход и переход нулевой ширины дают одинаковые записи.
  FlexRt показывает эффективную заливку. Исходная настройка может отличаться.
- Appearance, Fill pattern, Layout, Text format и холст используют Normal
  для свойств, зависящих от состояния. Холст растягивает рамку из
  `TILED_PICTURE`, сохраняя углы. Нажатие, фокус и выбор элемента списка
  по живому тегу не воспроизводятся.
- В окне FlexRt проверены обе вертикальные ориентации по центру и
  поворот на 90° с крайним выравниванием и разными отступами.
- Точное визуальное совпадение с TIA, другие версии TIA и несколько
  языков кнопки не проверены.
