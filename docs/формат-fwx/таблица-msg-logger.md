# MSG_LOGGER — функции классов алармов

Функции, привязанные к классам алармов; встречена одна — отправка письма (в
TIA: колонка **E-mail address** в HMI alarms → Alarm classes). Программа читает
таблицу в `Parsing/Panel/Alarms/MsgLoggerParser.cs`, начало элемента — общим с
`RECMSG` кодом `Parsing/Panel/Alarms/ClassListHeader.cs`
([таблица-recmsg.md](таблица-recmsg.md)). Адрес — в `FUNC_SEND_EMAIL`
([таблица-func-send-email.md](таблица-func-send-email.md)).

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md).
Проверено на шаговой копии A603A0097 (V21, адрес у одного класса,
`samples/a603-classes/`).

## Таблица

`Id` = 0x25. Один элемент во всех известных файлах, в том числе в панелях без
адресов (Project1, CCB-A13, A603A0097 до шагов) — там K = 0 и элемент
0x14 байт.

## Элемент

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u32 | 1 | наблюдение, не разобрано |
| +0x04 u32 | R — число ссылок (1) | установлено на файлах |
| +0x08 | R ссылок по 8 байт; встречена одна — на `MSG_HNDQUEUE` (0x1a) | наблюдение |
| дальше u16 | всегда 1 | наблюдение, не разобрано |
| u16 | K — число записей | установлено на шаговой копии |
| K × 8 байт | записи, см. ниже; элемент кончается ровно здесь | установлено на шаговой копии |

Запись:

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u16 | **ID класса** | установлено: адрес у класса 64 |
| +0x02 u16 | Id таблицы функции: `FUNC_SEND_EMAIL` (0x107) | наблюдение |
| +0x04 u16 | номер элемента в таблице функции | гипотеза: встречен только 0 |
| +0x06 u16 | 0 | наблюдение, не разобрано |

Пример (адрес у класса 64): `… 01 00 01 00 40 00 07 01 00 00 00 00`.

## Что делает программа

- Читает все записи; каждая сразу добавляется в документ.
- E-mail address класса — адрес элемента `FUNC_SEND_EMAIL`, на который
  указывает запись этого класса; если записей несколько, берётся первая.
  Записи на другие таблицы не используются.
- Элемент короче 8 байт, R больше 0x20, ссылки не помещаются в элемент или
  длина не сходится с K — `FwxFormatException` с таблицей и смещением:
  предупреждение, код 1. У классов, адрес которых не найден, E-mail address —
  `?`, а не пусто.
