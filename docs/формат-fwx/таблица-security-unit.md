# SECURITY_UNIT — группы пользователей

Группы User administration → User groups в TIA: номер, Display name и права.
Программа читает таблицу в `Parsing/Panel/UserGroupParser.cs` (лист «Группы
пользователей» — `Export/PanelData/Users/UserGroupsTable.cs`). Пользователи, пароли
и Automatic logoff в `pdata.fwc` не попадают (они в зашифрованном `pdata.pwx`) и
программой не читаются. Name группы, Comment и Display name прав в файле нет.

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md):
установлено на файлах, наблюдение, гипотеза.

## На чём проверено

- Шаговые копии Project1 (V21, TP700 Comfort, `data/real/steps-iofield/`, вне
  git), группы добавлял пользователь в TIA: 68 — третья группа Operators, Number 3,
  Display name `Group_1`, права по умолчанию (Operate); 69 — Number 5, только
  Monitor. Снимки User groups TIA — в истории сессии.
- `samples/pdata.fwc`, A603A0097, копии 46–67: две стандартные группы
  (Administrator group — все права, Users — Operate). Русские Display name
  групп A603A0097 («Operate», «Administrator group») сверены с TIA: так записано в
  проекте.

## Элемент

`Id` = 0x2e, элемент один.

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u32 | 1 | наблюдение |
| +0x04 u32 | R — число ссылок, во всех файлах 1 | наблюдение |
| +0x08 | R ссылок по 8 байт; ссылка на `GUI` 0: `16 00 00 00 82 00 82 00` | наблюдение |
| E+0x00 | 8 нулевых байт | наблюдение |
| E+0x08 | 4 байта `01 03 03 00` (A603A0097: `01 ff 03 00`) | не разобрано |
| E+0x0c u32 | **число групп + 1** (3 при двух группах, 4 при трёх — и при номерах 1–3, и при 1, 2, 5) | гипотеза по двум шагам |
| E+0x10 | 8 нулевых байт, u32 `0x3F7B7` | наблюдение, не разобрано |
| E+0x1c | записи групп по 12 байт до конца элемента | установлено |

E — конец ссылок (`+0x10` при R = 1).

Запись группы:

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u16 | **Number** группы | установлено (шаг 69: 3 → 5) |
| +0x02 u16 | всегда 1 | наблюдение |
| +0x04 u32 | **маска прав**: бит k — право с номером k + 1 в TIA (0 User administration, 1 Monitor, 2 Operate) | установлено (шаги 68–69: 4 → 2; 7 у Administrator group) |
| +0x08 u32 | номер строки `STRINGSTORE` с **Display name** группы на каждом языке | установлено (шаг 68: `Group_1`) |

Номер права в элементе `SECURITY_MONITO` (Authorization объекта, шаги 60–62
`data/real/steps-iofield/`) — тоже с нуля: 0 User administration, 1 Monitor,
2 Operate; в TIA у прав номера 1–3. Свои права (бит 3 и выше) не проверены.

## Как читает программа

Группы читаются по длине элемента: все целые записи с E+0x1c, каждая сразу в
документ. Число в заголовке − 1 не равно числу записей или после записей остался
хвост — предупреждение `SECURITY_UNIT @ 0x…: запись 1: групп по заголовку N, а
записей …`, прочитанные группы остаются. Начало элемента не сходится или записи не
помещаются — предупреждение, групп нет. Нет таблицы — групп нет, без сообщения.
