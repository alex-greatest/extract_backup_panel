# FUNC_LIST — список функций события экрана

События экрана Loaded и Cleared (в TIA: свойства экрана → Events) — списки
системных функций. Программа читает список в
`Parsing/Panel/Screens/FunctionListReader.cs`, события — в
`ScreenEventParser.cs`, функции — в [функции-func.md](функции-func.md).
Cleared ведёт к функциям через [таблица-adaptdemultiple.md](таблица-adaptdemultiple.md).

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md):
установлено на файлах, наблюдение, гипотеза.

## На чём проверено

Шаговые копии Project1 (V21, TP700 Comfort, `data/real/steps-events/`):

| Шаг | Что изменено в TIA |
|---|---|
| 09_loaded_setbit | `Screen_2` Loaded: SetBit `Bool_I0_0` |
| 10_cleared_setbit | SetBit перенесена в Cleared |
| 11_cleared_two | Cleared: SetBit и ResetBit |
| 12_setbit_other_tag | тег SetBit → `Bool_I1_5` |
| 13_both_events | Loaded SetBit + Cleared из шага 12 |
| 20_all_functions, 21_project_objects | по одной функции на экран в Loaded (82 функции) |
| 22_screen_objects | функции объектов экрана в Loaded и Cleared экранов `Obj`, `Obj2`, `Obj2_1` (66) |
| 23_screenobject_page_hb | ScreenObjectPageUp/Down на HTML-браузере |
| 24_settag_db_member | `Obj_P` Loaded: SetTag на член DB `xxxx_2.Element_1`, 7 |

Карта функций каждой копии 20–22 (экран, функция, параметры из TIA, таблица,
байты) — `*.json` рядом с копиями. Ещё 13 экранов A603A0097 (события сверены с
TIA через Openness, V21) и Root screen
`samples/pdata.fwc` (SetTag `Tag_ScreenNumber` 1 — видно в TIA).

## Ссылка из SCREEN

| Ссылка записи экрана | Событие | Статус |
|---|---|---|
| `2a 00 <k> 00 ff ff ff ff` — Id `FUNC_LIST`, элемент k | **Loaded** (даже с одной функцией) | установлено (шаги 09–13, 20–22) |
| `39 00 <k> 00 00 00 39 80` — Id `ADAPTDEMULTIPLE`, элемент k | **Cleared** | установлено |

Слова ссылки не читаются: событие различается по таблице. Новый список
компилятор вставляет в начало таблицы — номера чужих списков сдвигаются
(наблюдение, шаг 09).

## Элемент

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u32 | 1 | наблюдение |
| +0x04 u32 | R — число ссылок: у Loaded 1, у списка Cleared 0 | наблюдение |
| +0x08 | R ссылок по 8 байт: у Loaded — `ADAPTDEMULTIPLE` условия «текущий экран (`VARSYS` CurScreen) = номер экрана» | гипотеза (номер совпал на шагах 09, 13), не читается |
| за ссылками u16 | N — число функций (TIA даёт не больше 16) | установлено |
| далее | N пар (u16 Id таблицы `FUNC_*`, u16 номер элемента) в порядке TIA | установлено |

Одна функция с ошибкой компиляции убирает из файла весь список (наблюдение).

## Как читает программа

- Первая ссылка экрана на `FUNC_LIST` — Loaded; функции — пары по порядку.
- Ссылка за последний элемент (в сообщении — имя экрана), элемент вне таблицы, первое слово не 1, R > 0x20,
  ссылки или пары не помещаются, Id таблицы пары нет в TOC —
  `FwxFormatException` с таблицей и смещением: предупреждение, событие
  «не прочитано», остальные экраны и события читаются.
- Нет таблицы — событий Loaded нет, без сообщения.
