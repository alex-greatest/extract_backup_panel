# MSG_ANALOGHANDL — классы аналоговых алармов

Обработчик аналоговых алармов: число алармов, список ID и классы. Программа
читает таблицу в `Parsing/Panel/Alarms/MsgAnalogHandlParser.cs`, раскладку — общим с
`MSG_NUMHANDLER` кодом `Parsing/Panel/Alarms/AlarmHandlerLayout.cs`. На номер класса
ссылается аларм в `MSG_ANALOGCREAT`
([таблица-msg-analogcreat.md](таблица-msg-analogcreat.md)).

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md).

## Элемент

`Id` = 0x123. Один элемент во всех файлах, в том числе в панелях без аналоговых
алармов (A603A0097 до шагов, CCB-A13, Project1). Раскладка та же, что у
`MSG_NUMHANDLER` ([таблица-msg-numhandler.md](таблица-msg-numhandler.md)):

| Смещение | Значение | Статус |
|---|---|---|
| +0x00…+0x2b | те же байты, что у `MSG_NUMHANDLER` | наблюдение, не разобрано |
| +0x2c u16 | N — число аналоговых алармов (0 в панелях без них) | установлено на шаговых копиях: 0, 1, 3, 4 |
| +0x2e | u16[N] — ID алармов по возрастанию; u16[N] — номер элемента `MSG_ANALOGCREAT` в том же порядке | наблюдение: `1, 2, 7` и `1, 2, 0` |
| +0x2e + 4·N u16 | число классов K | установлено на файлах |
| дальше | K записей классов по 0x24 байта | как у `MSG_NUMHANDLER` |

Список классов у A603A0097 и CCB-A13 тот же, что в `MSG_NUMHANDLER` (6 и 9
классов в том же порядке). Программа всё равно берёт класс аналогового аларма
из этой таблицы: аларм ссылается на номер в ней.

## Что делает программа

- Читает записи классов в отдельный список аналоговых алармов.
- Лист «Классы алармов» берёт этот список, только если список `MSG_NUMHANDLER`
  пуст (в известных файлах списки одинаковы).
- Длина элемента не сходится с N и K — `FwxFormatException`: предупреждение;
  у аналоговых алармов класс `?`.
