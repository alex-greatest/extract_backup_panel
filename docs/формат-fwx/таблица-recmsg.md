# RECMSG — классы журнала алармов

Какие классы алармов пишутся в журнал алармов (в TIA: колонка **Log** в
HMI alarms → Alarm classes). Программа читает таблицу в
`Parsing/Panel/Alarms/RecMsgParser.cs`, начало элемента — общим с `MSG_LOGGER`
кодом `Parsing/Panel/Alarms/ClassListHeader.cs`. Имя журнала — в `ARCHIVES`
([таблица-archives.md](таблица-archives.md)): журнал ссылается на элемент
`RECMSG`.

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md).
Проверено на шаговых копиях A603A0097 (V21, один журнал алармов
`OP70_AlarmsHistory`, `samples/a603-classes/`) и Project1 (V21, два журнала
алармов у двух классов — элемент на журнал, `samples/project1-classes/`).

## Таблица

`Id` = 0x43. Есть только в панелях с журналом алармов: в A603A0097 — один
элемент; в `samples/pdata.fwc` (Project1) и CCB-A13 таблицы нет.

## Элемент

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u32 | 1 | наблюдение, не разобрано |
| +0x04 u32 | R — число ссылок (1) | установлено на файлах |
| +0x08 | R ссылок по 8 байт: u16 Id таблицы, u16 номер элемента, два u16; встречена одна — на `MSG_HNDQUEUE` (0x1a) | наблюдение |
| дальше u16 | всегда 2 | наблюдение, не разобрано |
| u16 | K — число классов | установлено на шаговых копиях |
| K × u16 | **ID классов**, которые пишутся в журнал (`ID` в [таблица-msg-numhandler.md](таблица-msg-numhandler.md)) | установлено: включение Log у Warnings добавило ID 2 |
| дальше | нули до кратности 4; элемент кончается ровно здесь | установлено на файлах |

Пример (A603A0097 после шагов, Log у Errors и Warnings):
`01 00 00 00 01 00 00 00 1a 00 00 00 6c 00 6c 00 02 00 02 00 01 00 02 00`.

## Что делает программа

- Читает все элементы; каждый сразу добавляется в документ.
- Нет таблицы — у классов без журнала Log `<No log>`.
- Элемент короче 8 байт, R больше 0x20, ссылки не помещаются в элемент или
  длина не сходится с K — `FwxFormatException` с таблицей и смещением:
  предупреждение. У классов, журнал которых не найден, Log — `?`, а не
  `<No log>`.
- Log класса — имя журнала `ARCHIVES`, ссылающегося на элемент с ID класса;
  если журналов несколько, берётся первый в порядке `ARCHIVES` (несколько
  журналов алармов не встречались).
