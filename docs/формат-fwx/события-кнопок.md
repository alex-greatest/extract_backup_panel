# События кнопок

FlexRt читает назначения Button из `VIEW_BUTTONS` и `VIEW_STATEBUTTO`.
Раскладка установлена на шаговых компиляциях Project1 для TP700 Comfort
(Runtime 17.0.0.0, TIA Portal V21 Update 1).

## Ссылки на события

В каждой восьмибайтной ссылке кнопки второе служебное слово u16
находится на `+0x06`. Слово определяет событие с учётом целевой таблицы.

| Событие | VIEW_BUTTONS | VIEW_STATEBUTTO |
| --- | --- | --- |
| Click | `0x8000` | `0x801b` |
| Press | `0x8019` | `0x8019` |
| Release | `0x801a` | `0x801a` |
| Activate | `0x8039`, ADAPTDEMULTIPLE, значение 1 | то же |
| Deactivate | `0x8039`, ADAPTDEMULTIPLE, значение 0 | то же |
| Change | `0x801b` | `0x8000` |

У Activate и Deactivate значение u32 стоит сразу за единственной ссылкой
`ADAPTDEMULTIPLE`. Ссылка ведёт на вызов или список. Этот посредник общий
с I/O field. У кнопки остальные четыре события используют слова из
таблицы выше. Слово `0x8000` встречается также в ссылках на свойства.

Одиночный вызов хранится прямой ссылкой, несколько вызовов идут через
[`FUNC_LIST`](таблица-func-list.md). Порядок и повторы сохраняются.
Пустой обработчик в обратном XML проверенных образцов не даёт ссылки
на событие в FWC. У Press, Release, Click и Change с правом User
administration проверена обёртка `SECURITY_MONITO`: одна ссылка ведёт
на `SECURITY_UNIT`, другая — на вызов или список. У Activate и
Deactivate при том же праве в XML цепочка через `ADAPTDEMULTIPLE`
ведёт прямо к вызову или списку. Проверка права опирается на контрольные
назначения, а не на перебор всех прав и функций.

У `SetBitWhileKeyPressed` проверено одно назначение Press в XML.
Компилятор записал в FWC пару `FUNC_BITWORD`: подкод 1 для Press,
подкод 0 для Release. FlexRt показывает оба скомпилированных вызова.
Системные вызовы и `FUNC_SCRIPT` описаны в [разборе функций](функции-func.md).

## DirectKey

Подтверждённый блок хранится в `SCREEN` после цвета фона. Пусть `p` —
конец пар объектов `SCREEN`, а `N` — число пар. Метка находится по
смещению `p + ceil(N / 2) * 4 + 0x0c`.

| От метки | Поле |
| --- | --- |
| `+0x00` | u32 `0x14ff` |
| `+0x04` | u32 размер после поля размера, `4 + число записей * 0x0a` |
| `+0x08` | u16 `0xffff` |
| `+0x0a` | u16 число записей |
| `+0x0c` | записи по `0x0a` байт: i16 left, top, right, bottom и u16 Bit |

FlexRt связывает запись с единственной кнопкой с совпадающей рамкой
на том же экране. Для обычного экрана учитывается вертикальный сдвиг
Permanent area. Поддерживаемый диапазон Bit — 0–31. Назначение показывается
первым вызовом Press, перед функциями из ссылок самой кнопки. Биты 0 и 31,
несколько назначений, сдвиг и сохранение цвета фона проверены на контрольных
образцах.

## Границы проверки

Проверены все шесть событий, сосуществование назначений, одиночные вызовы,
списки, порядок и повторы. Контрольные кнопки включали Text, TextCheckBack,
Graphic, GraphicCheckBack и Invisible. На ошибке списка FlexRt сохраняет
распознанное событие как «не прочитано». При ошибке одиночного вызова
остальные вызовы сохраняются. При повреждении поля условия Activate или
Deactivate определить событие по этой ссылке нельзя.

Контрольные файлы лежат в локальном архиве исследования
`D:/ButtonEventsResearch-20261124`. Привязки и права сверены в
`event-serialization-matrix.json` и `order-and-repetition-verification.json`.
В `Continuation/` файлы `flexrt-second-review-system-comparison.json`,
`flexrt-second-review-vb-comparison.json` и
`flexrt-second-review-targeted.json` фиксируют сверку FlexRt с 1038
системными назначениями, 49 вызовами VB и 15 дополнительными проверками.
Набор проверок подтверждает прочитанные назначения. Доступность всего
каталога редактора TIA для TP700 по нему не устанавливается.
