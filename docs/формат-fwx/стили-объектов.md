# Стили объектов — PS_BorderedShap, PS_Text, PS_Fill_Color, FONT

Цвета, рамка, выравнивание и шрифт объекта лежат не в его элементе, а в общих
таблицах стилей: элемент объекта ссылается на запись каждой. Одинаковые
сочетания значений — одна запись; новая появляется только при новом сочетании
(шаг 15: фон 255, 0, 0 — новая запись `PS_Fill_Color` 9 вместо 8). Программа
читает их в `Parsing/Panel/Screens/` (`BorderStyleReader`, `TextStyleReader`,
`FillStyleReader`, `FontReader`, общий `StyleElement`); пока — только для I/O
field ([поле-ввода-вывода.md](поле-ввода-вывода.md)).

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md).
Проверено на шагах `data/real/steps-iofield/` 15–32, 41–45 и 48 (Project1, V21,
TP700 Comfort) и на 105 полях A603A0097 против выгрузки Openness. Таблица по
ссылке выбирается по Id из TOC: имена таблиц не уникальны (две
`PS_BorderedShap`).

## PS_BorderedShap (64 байта)

| Смещение | Поле | Статус |
|---|---|---|
| +0x14 | u16 Style: 1 — одинарная линия (Solid, а также Dash, Dot, DashDot, DashDotDot — один код), 2 — Double line | установлено |
| +0x16 | u16 Border width | установлено |
| +0x18 | R, G, B, 0 — Border color | установлено |
| +0x1c | R, G, B, 0 — Border background color | установлено |
| +0x20 | 4 × u16 Corner radius (всегда равны; TIA задаёт один) | установлено |
| +0x3a | u16 Id `TILED_PICTURE` (0x15c) и u16 номер элемента — картинка рамки (PNG 23×23 у поля шагов 70–72); картинки нет — `ffff 0000` (запись 0) | наблюдение (шаги 70b–72), программа не читает |
| остальное | не разобраны | — |

## PS_Text (32 байта)

| Смещение | Поле | Статус |
|---|---|---|
| +0x14 | R, G, B, 0 — цвет текста | установлено |
| +0x18 | байт по горизонтали: 0 Right, 1 Center, 2 Left | установлено |
| +0x19 | байт по вертикали: 0 Top, 1 Middle, 2 Bottom | установлено |
| +0x1c | 4 байта Margins, px: Top, Bottom, Left, Right; элемент короче 0x20 — Margins не прочитаны, предупреждение, остальное читается | установлено |

## PS_Fill_Color (24 байта)

| Смещение | Поле | Статус |
|---|---|---|
| +0x14 | R, G, B, 0 — цвет фона | установлено |

## FONT (116 байт)

| Смещение | Поле | Статус |
|---|---|---|
| +0x14 | u32 `0x409` | наблюдение (гипотеза: язык) |
| +0x1c | u32 высота = Font size × 7500 (16 → 120000, 20 → 150000) | установлено на двух размерах |
| +0x24 | u16 вес: 400 Regular, 700 Bold | установлено |
| +0x28 | u32 1 — Italic | установлено |
| +0x2c | u32 1 — Underline | установлено |
| +0x34 | имя UTF-16LE до нуля | установлено |

Шрифт Arial TIA при компиляции заменяет на `Tahoma` (шаг 32), Courier New
записывает как есть (шаг 45): в файле — шрифт, которым рисует панель.
Strikeout не проверялся.
