# GUI — стартовый экран

Общие настройки экрана панели; программа читает из таблицы только номер
стартового экрана (в TIA: Runtime settings → General → Start screen) — в
`Parsing/Panel/Screens/GuiParser.cs`. Экраны —
[таблица-screen.md](таблица-screen.md).

Статусы — как в [таблица-datalink-readwr.md](таблица-datalink-readwr.md):
установлено на файлах, наблюдение, гипотеза.

## На чём проверено

Шаговые копии Project1 (V21, TP700 Comfort, `data/real/steps-screens/`):
стартовый `Root screen` (номер 1) — `01 00`; стартовый `Screen_2` (номер 3) —
`03 00`; номер `Screen_2` 3 → 5 — `05 00`. A603A0097 — `998` (`998_LOGIN`),
CCB-A13 и остальные образцы — `1`.

## Элемент

`Id` = 0x16. Во всех файлах один элемент длиной 0x7c (124 байта).

| Смещение | Значение | Статус |
|---|---|---|
| +0x00 u32 | всегда 1 | наблюдение |
| +0x04 u32 | R — число ссылок, во всех файлах 3 | наблюдение |
| +0x08 | 3 ссылки: `VARSYS` 1 и 2, `FUNC_MSGWIN` 2 | наблюдение |
| +0x20 (+0x00 от конца ссылок) | `00 00 07 00` — одинаково во всех файлах | наблюдение, не разобрано |
| +0x24, +0x28 u32 | ширина и высота панели (800×480, 1366×768, 1280×800) | наблюдение |
| +0x2c…+0x33 | `05 00 00 00 68 00 01 00` — одинаково во всех файлах | наблюдение, не разобрано |
| **+0x34** (+0x14 от конца ссылок) u16 | **номер стартового экрана** (Screen number) | установлено на файлах |
| +0x36… | не разобрано, одинаково в шаговых копиях | наблюдение |

Номер, а не номер записи `SCREEN`: в A603A0097 — 998, а записей 56. Экран по
номеру находится через [таблица-adaptvaluechang.md](таблица-adaptvaluechang.md).

## Что делает программа

- Читает из первого элемента только номер стартового экрана.
- Нет таблицы — стартовый экран «неизвестно», без сообщения.
- Элемент короче 8 байт, R > 0x20, ссылки или номер не помещаются в элемент —
  `FwxFormatException`: предупреждение, стартовый экран «неизвестно».
- «Сводка» и вкладка Info окна: `Стартовый экран: Root screen (1)`; номер есть, а экрана
  с ним нет — `неизвестно (5)`. На листе «Экраны» у этого экрана Start screen —
  `Yes`.
