# FlexRt

Окно просмотра, которое восстанавливает данные панели Siemens Comfort из бэкапа
панели — без исходного проекта TIA Portal: HMI-теги, системные события,
дискретные и аналоговые алармы, классы и группы алармов, экраны, картинки.

## Что делает

Читает скомпилированную конфигурацию панели (`pdata.fwc` из бэкапа панели или
из папки `Generates` проекта TIA) и, если выбраны, данные ПЛК — проект TIA
(`System\PEData.plf`) или копию карты памяти ПЛК (папка с `SIMATIC.S7S`).

Показывает экраны панели, таблицы листов, картинки, текст чтения (вкладка Info)
и предупреждения (вкладка «Ошибки»). По кнопкам, через «Сохранить как»,
сохраняет:

- `panel_data.xlsx` — вся книга или текущий лист:
  - «Сводка» — IP панели, соединения, ПЛК и модель CPU;
  - «Теги» — статистика и таблица тегов как в HMI tags в TIA: имя, тип,
    соединение, ПЛК, тег ПЛК, адрес, режим доступа, цикл, комментарий из ПЛК;
  - «Системные события», «Дискретные алармы», «Аналоговые алармы», «Классы
    алармов», «Группы алармов», «Экраны» — как соответствующие списки в TIA;
- `PDATA.xlsx` — тексты всех языков панели;
- выбранную картинку (PNG, JPEG) или все картинки архивом `images.zip`.

## Запуск

Нужны .NET 10, Windows и WebView2.

```
dotnet run --project src/FlexRt.Ui
```

Панель открывается кнопкой «Открыть pdata.fwc…», данные ПЛК выбираются кнопкой
«Данные ПЛК». Подробнее — `docs/текущее-поведение/окно-просмотра.md`. Тесты:
`dotnet test FlexRt.sln`.

## Проверено

TIA Portal V17, V19 и V21, панели TP700, TP1500 и TP1900 Comfort, ПЛК S7-1500 и
S7-1200. Форматы закрытые и разобраны по реальным файлам; подробности — в `docs/`.
