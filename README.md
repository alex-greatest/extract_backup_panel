# FlexRt

Консольная программа и окно просмотра, которые восстанавливают данные панели
Siemens Comfort из бэкапа панели — без исходного проекта TIA Portal: HMI-теги,
системные события, дискретные и аналоговые алармы, классы и группы алармов,
экраны, картинки.

## Что делает

Читает скомпилированную конфигурацию панели (`pdata.fwc` из бэкапа панели или
из папки `Generates` проекта TIA) и, если есть, данные ПЛК — проект TIA
(`System\PEData.plf`) или копию карты памяти ПЛК (папка с `SIMATIC.S7S`).

На выходе:

- `panel_data.xlsx`
  - «Сводка» — модель панели, версия Runtime, IP панели, соединения, ПЛК и
    модель CPU;
  - «Теги» — статистика и таблица тегов как в HMI tags в TIA: имя, тип,
    соединение, ПЛК, тег ПЛК, адрес, режим доступа, цикл, комментарий из ПЛК;
  - «Системные события», «Дискретные алармы», «Аналоговые алармы», «Классы
    алармов», «Группы алармов», «Экраны» — как соответствующие списки в TIA;
  - «Ошибки» — если данные ПЛК сломаны;
- `PDATA.xlsx` — тексты всех языков панели;
- папка `images` — картинки панели (PNG, JPEG) файлами;
- hex-выгрузка всех таблиц `pdata.fwc` для исследования формата;
- `logs\flexrt-<дата>.log` — лог запуска.

## Запуск

Нужен .NET 10.

```
dotnet run --project src/FlexRt
```

Пути заданы константами в начале `src/FlexRt/Program.cs`; переменные окружения
`FLEXRT_INPUT` (панель), `FLEXRT_PLC` (файл `PEData.plf` или папка карты ПЛК) и
`FLEXRT_OUT` (каталог результата) их подменяют. Тесты: `dotnet test FlexRt.sln`.

## Окно просмотра

```
dotnet run --project src/FlexRt.Ui
```

Нужны Windows и WebView2. Окно открывает `pdata.fwc` кнопкой «Открыть
pdata.fwc…» и показывает экраны панели: дерево проекта как в TIA, прямоугольник
экрана в его размере, свойства экрана (как строка листа «Экраны») и
предупреждения разбора. Только просмотр: данные ПЛК не читаются, файлы не
пишутся. Подробнее — `docs/текущее-поведение/окно-просмотра.md`.

## Проверено

TIA Portal V17, V19 и V21, панели TP700, TP1500 и TP1900 Comfort, ПЛК S7-1500 и
S7-1200. Форматы закрытые и разобраны по реальным файлам; подробности — в `docs/`.
