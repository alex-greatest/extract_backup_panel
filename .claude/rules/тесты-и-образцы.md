# Тестовый проект, образцы и эталоны

Образцы, эталоны и тесты меняются только по решению пользователя (см. «Тесты — только по
прямому запросу» в `CLAUDE.md`).

## Образцы и эталоны

- `samples/` — `plc-udt/`: `pdata.fwc` и `PEData.plf` тестового проекта с одним
  ПЛК и пользовательским типом (члены тега входов и DB этого типа) и его карта
  `PLC_1-card.zip` (лист «Теги» по ней совпадает с листом по PEData.plf), эталон
  `expected/plc-udt/теги.txt`. Ещё реальный `pdata.fwc` (TIA V17 / TP700 Comfort, 16 записей `VAR`:
  15 тегов из HMI tags и скрытый `@DiagnosticsIndicatorTag`; копия шага 14),
  его обрезанная копия `bad.fwc` и эталонный вывод `expected/` для
  проверки перед завершением. `plc/` — `pdata.fwc` (TIA V21, 69 записей
  `VAR`, PLC-теги, два соединения), `pdata-one-connection.fwc` (тот же
  проект до второго соединения, 66 записей `VAR`, шаг `05_absolute`) и проект
  ПЛК `PEData.plf` (2 ПЛК, ещё `PLC_1-card.zip` — карта `PLC_1` того же проекта,
  записанная TIA через Card Reader; лист «Теги» по ней совпадает с листом по
  `PEData.plf`;
  51 тег ПЛК). `card/` — `pdata.fwc` реального бэкапа панели CCB-A13
  (TP1500 Comfort, Runtime V17, 517 записей `VAR`) с его
  `ProjectCharacteristics.rdf` и `BuildInfo.txt` и копия карты ПЛК одним
  архивом `CCB-A03.zip` (S7-1500F, TIA V19, 591 тег ПЛК, 95 DB; 128 файлов
  карты в архиве, чтобы не засорять git — тесты распаковывают его во временный
  каталог). `a603/` — `pdata.fwc` реального проекта A603A0097 (TIA V21, TP1900
  Comfort, 3 языка, 355 дискретных алармов) после шаговых правок алармов,
  сверенных с TIA; эталон `expected/a603/дискретные-алармы-сверено.txt` — строки
  листа по 15 сверенным алармам (без данных ПЛК). `a603-analog/` — `pdata.fwc`
  того же проекта после шаговых правок аналоговых алармов (4 аларма: пределы
  Int, Real, UInt и тег, поле тега в тексте); эталон
  `expected/a603-analog/аналоговые-алармы.txt` — лист «Аналоговые алармы» целиком,
  сверен с TIA (ячейки через ` | `). `a603-classes/` — `pdata.fwc` того же
  проекта после шаговых правок классов алармов (State machine, Log, E-mail
  address, цвета, тексты состояний), сверенных с TIA; эталон
  `expected/a603-classes/классы-алармов.txt` — лист «Классы алармов» целиком
  (ячейки через ` | `). `project1-classes/` — `pdata.fwc` Project1 (V21) с
  цветами классов, двумя журналами алармов и двумя адресами у классов 65 и 66,
  сверенными с TIA. `project1-groups/` — `pdata.fwc` Project1 (V21) после шаговых
  правок групп алармов, сверенных с TIA: дискретные алармы 1–4 в группах 17, 1
  (с Report), 2, 2; дискретный 4 на абсолютном `%MW10` с квитированием HMI
  внутренним тегом; аналоговые 1–7 с пределами Int, DInt, Real, LReal и
  внутренними тегами срабатывания; тег `HMI_Tag_1` с Display name.
  `screens/05_popup.fwc` — шаговая копия Project1 (V21) из `data/real/steps-screens/`,
  сверенная с TIA: экраны `Root screen` (1), `Screen_1` (2), `Screen_2` (5,
  стартовый, шаблон у него снят), pop-up `Pop-up screen_1` 400×200.
  Эталоны:
  `expected/теги.txt`, `expected/plc/теги.txt` (`pdata-one-connection.fwc` +

  Openness) и `expected/card/теги.txt` —
  слепки листа «Теги»; `expected/системные-события.txt` — слепок листа «Системные

  `expected/plc/pdata.sha256` (386) — манифесты hex-вывода в формате
  `sha256sum` (`<хэш>  <путь через />`). Папка `expected/pdata/` с самими
  hex-файлами исключена из git и необязательна.

## Тестовый проект

- `tests/FlexRt.Tests/` — `Unit/` (чистые функции: `FwxBinary`, коды и
  адреса ПЛК, `Plc/Plf/PlfText`, `ExcelCell`, `LanguageText`,
  `ReportTableWriter`, `Export/PanelData/TagTypeNames`,
  `TagRowFormatter`, `AlarmBitAddress`, `AlarmText`, `AnalogLimitValue`; `Plc/Card/` — `CardXml`, `CardTagParser`,
  `CardDbParser`, `CardInterfaceBuilder`; `Panel/PanelFilesReader` — копии
  файлов `samples/card/` во временном каталоге; `Panel/PictureSizeTests` — размер
  картинок `samples/pdata.fwc` и `samples/a603/pdata.fwc` (ожидания — раскодировано
  браузером окна), байты заполнения и маркеры без длины в копии JPEG, обрезанные файлы;
  `Export/PictureArchiveExporterTests` — архив картинок окна на `samples/a603/pdata.fwc`:
  записи в корне, имена и порядок ядра, байты как в папке `images` консоли, без
  сжатия, прежний файл перезаписывается; `Export/PanelData/ReportSheetsExporter`
  — раскладка листов книги окна; `Export/PanelData/WindowWorkbookTests` — книга
  окна (листы `PanelDataBook.TryBuild`, записанные `ReportSheetsExporter`) равна
  книге консоли ячейка в ячейку на `samples/pdata.fwc` и
  `samples/project1-groups/pdata.fwc`, порядок листов `PanelDataBook.Sheets` —
  явный список в тесте, консоль пишет листы, которые есть по описанию, по
  порядку и «Ошибки» последним, при сбое сопоставления с ПЛК не построены
  только «Теги» и «Дискретные алармы» (их листы пустые); файлы — во временный каталог) и `Integration/` (программа
  отдельным процессом на файлах `samples/`, карта — распаковкой
  `CCB-A03.zip` во временный каталог; испорченные входы — копии `samples/`,
  изменённые в рантайме, в том числе испорченные `MSG_NUMEVENT`, `MSG_NUMHANDLER`,
  `AREAPTR`, `MSG_ANALOGCREAT`, `MSG_ANALOG_OBSE`, `MSG_ANALOGHANDL`, `RECMSG`,
  `ARCHIVES`, `MSG_LOGGER`, `FUNC_SEND_EMAIL`, `SCREEN`, `ADAPTVALUECHANG`,
  `GUI` и длина в `PICTURE`; листы «Теги», «Сводка», «Системные события»,
  «Дискретные алармы», «Аналоговые алармы», «Классы алармов», «Группы алармов» и
  «Экраны»; файлы папки `images`). Программа ничего не печатает: `FlexRtProcess.Run`
  требует пустые stdout и stderr процесса, а текст запуска (`ProgramRun.Output` —
  строки `Info`, `ProgramRun.Errors` — `Warning`/`Error`) берёт из того же запуска
  `ExtractionRun` с `RunTranscript` внутри процесса теста; его коды возврата
  совпадают; в логе процесса (`logs/flexrt-*.log`) должны быть строка старта с
  переданными путями панели и ПЛК, код возврата и запись для каждого
  предупреждения, ошибки, строки «Файл ПЛК:» и итога экспорта из текста запуска
  (`ProcessLogLines` переводит строку текста в фрагмент лога; предупреждение без
  правила — ошибка теста); каталога результата до запуска быть не должно, после запуска внутри теста он удаляется — файлы проверяются от
  процесса. Каждый
  интеграционный тест пишет в свой временный каталог через `FLEXRT_OUT` и
  удаляет его; `data/out` тесты не трогают. Хост — `DOTNET_HOST_PATH`, иначе
  `dotnet` из PATH. `Extraction/` — `ExtractionRun` внутри процесса на файлах
  `samples/` с подставным `RecordingReporter`: порядок событий, код возврата,
  «не поддерживается», независимость экспортов, сбой сообщения об успехе
  экспорта; выходы — во временный каталог.

## Данные вне git

- `data/` — `out/` (результат) и `real/` — реальные копии
  `pdata.fwc`, в том числе пошаговые `real/steps/` (V17, внутренние теги),
  `real/steps-v21/` (V21, PLC-теги) и `real/steps-screens/` (V21, экраны
  Project1). Каталог исключён из git.
- Вне репозитория, на Рабочем столе: проекты TIA `extract_backup_data\Project1`,
  `Project1_upload` (выгружен из PLCSIM), `Project1_plc_only`,
  `A603A0097_V21` / `A603A0097` (реальный, DB, 3 языка, Openness-эталон в
  `A603A0097\openness_export\`), `半自动驱动轴装配线03_06_2026[_V21]` (S7-1200).
