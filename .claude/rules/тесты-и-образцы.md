# Тестовый проект, образцы и эталоны

Образцы, эталоны и тесты меняются только по решению пользователя (см. «Тесты — только по
прямому запросу» в `CLAUDE.md`).

## Образцы и эталоны

- `samples/` — `plc-udt/`: `pdata.fwc` и `PEData.plf` тестового проекта с одним
  ПЛК и пользовательским типом (члены тега входов и DB этого типа) и его карта
  `PLC_1-card.zip` (лист «Теги» по ней совпадает с листом по PEData.plf), эталон
  `expected/plc-udt/теги.txt`. Ещё реальный `pdata.fwc` (TIA V17 / TP700 Comfort, 16 записей `VAR`:
  15 тегов из HMI tags и скрытый `@DiagnosticsIndicatorTag`; копия шага 14),
  его обрезанная копия `bad.fwc` и эталонный вывод `expected/` для
  проверки перед завершением. `plc/` — `pdata.fwc` (TIA V21, 69 записей
  `VAR`, PLC-теги, два соединения), `pdata-one-connection.fwc` (тот же
  проект до второго соединения, 66 записей `VAR`, шаг `05_absolute`) и проект
  ПЛК `PEData.plf` (2 ПЛК, ещё `PLC_1-card.zip` — карта `PLC_1` того же проекта,
  записанная TIA через Card Reader; лист «Теги» по ней совпадает с листом по
  `PEData.plf`;
  51 тег ПЛК). `card/` — `pdata.fwc` реального бэкапа панели CCB-A13
  (TP1500 Comfort, Runtime V17, 517 записей `VAR`) с его
  `ProjectCharacteristics.rdf` и `BuildInfo.txt` и копия карты ПЛК одним
  архивом `CCB-A03.zip` (S7-1500F, TIA V19, 591 тег ПЛК, 95 DB; 128 файлов
  карты в архиве, чтобы не засорять git — тесты распаковывают его во временный
  каталог). `a603/` — `pdata.fwc` реального проекта A603A0097 (TIA V21, TP1900
  Comfort, 3 языка, 355 дискретных алармов) после шаговых правок алармов,
  сверенных с TIA; эталон `expected/a603/дискретные-алармы-сверено.txt` — строки
  листа по 15 сверенным алармам (без данных ПЛК). `a603-analog/` — `pdata.fwc`
  того же проекта после шаговых правок аналоговых алармов (4 аларма: пределы
  Int, Real, UInt и тег, поле тега в тексте); эталон
  `expected/a603-analog/аналоговые-алармы.txt` — лист «Аналоговые алармы» целиком,
  сверен с TIA (ячейки через ` | `). `a603-classes/` — `pdata.fwc` того же
  проекта после шаговых правок классов алармов (State machine, Log, E-mail
  address, цвета, тексты состояний), сверенных с TIA; эталон
  `expected/a603-classes/классы-алармов.txt` — лист «Классы алармов» целиком
  (ячейки через ` | `). `project1-classes/` — `pdata.fwc` Project1 (V21) с
  цветами классов, двумя журналами алармов и двумя адресами у классов 65 и 66,
  сверенными с TIA. `project1-groups/` — `pdata.fwc` Project1 (V21) после шаговых
  правок групп алармов, сверенных с TIA: дискретные алармы 1–4 в группах 17, 1
  (с Report), 2, 2; дискретный 4 на абсолютном `%MW10` с квитированием HMI
  внутренним тегом; аналоговые 1–7 с пределами Int, DInt, Real, LReal и
  внутренними тегами срабатывания; тег `HMI_Tag_1` с Display name.
  `screens/05_popup.fwc` — шаговая копия Project1 (V21) из `data/real/steps-screens/`,
  сверенная с TIA: экраны `Root screen` (1), `Screen_1` (2), `Screen_2` (5,
  стартовый, шаблон у него снят), pop-up `Pop-up screen_1` 400×200.
  Эталоны:
  `expected/теги.txt`, `expected/plc/теги.txt` (`pdata-one-connection.fwc` +
  `PEData.plf`; 67 его строк совпали с прежним эталоном, сверенным через
  Openness) и `expected/card/теги.txt` —
  слепки листа «Теги»; `expected/системные-события.txt` — слепок листа «Системные
  события» по `pdata.fwc` (585 событий, сверены с TIA; ячейки через ` | `, перенос
  строки как `\n`); `expected/card/дискретные-алармы.txt` — слепок листа
  «Дискретные алармы» по `card/pdata.fwc` с картой (2000 алармов, с TIA не сверен:
  проекта нет; ячейки через ` | `). `expected/pdata.sha256` (264 файла) и
  `expected/plc/pdata.sha256` (386) — манифесты разбиения таблиц на элементы
  (сняты с hex-выгрузки удалённой консоли) в формате `sha256sum`
  (`<хэш>  <путь через />`); сверяет их тест `RunAssertions.TablesMatch`
  в памяти, файлов не пишет. Папка `expected/pdata/` с
  самими hex-файлами исключена из git и необязательна.

## Тестовый проект

- `tests/FlexRt.Tests/` — `Unit/` (чистые функции: `FwxBinary`, коды и
  адреса ПЛК, `Plc/Plf/PlfText`, `ExcelCell`, `LanguageText`,
  `ReportTableWriter`, `Export/PanelData/TagTypeNames`,
  `TagRowFormatter`, `AlarmBitAddress`, `AlarmText`, `AnalogLimitValue`; `Plc/Card/` — `CardXml`, `CardTagParser`,
  `CardDbParser`, `CardInterfaceBuilder`; `Panel/PictureSizeTests` — размер
  картинок `samples/pdata.fwc` и `samples/a603/pdata.fwc` (ожидания — раскодировано
  браузером окна), байты заполнения и маркеры без длины в копии JPEG, обрезанные файлы;
  `Export/PictureArchiveExporterTests` — архив картинок окна на `samples/a603/pdata.fwc`:
  записи в корне, имена `PictureArchiveExporter.EntryName` в порядке ядра, байты
  — как у `doc.Pictures`, без сжатия, прежний файл перезаписывается;
  `Export/PanelData/ReportSheetsExporter` — раскладка листов книги окна;
  `Export/PanelData/WindowWorkbookTests` — книга окна (листы
  `PanelDataBook.TryBuild`, записанные `ReportSheetsExporter`) на
  `samples/pdata.fwc` и `samples/project1-groups/pdata.fwc` — листы, которые есть
  по описанию книги, в его порядке, все построены, листа «Ошибки» нет
  (`WindowBook_FollowsBookDescription`); порядок листов `PanelDataBook.Sheets` —
  явный список в тесте; при сбое сопоставления с ПЛК не построены только «Теги»
  и «Дискретные алармы» (их листы пустые); файлы — во временный каталог) и
  `Integration/` (открытие панели и сохранение её файлов внутри процесса теста
  на файлах `samples/`, карта — распаковкой `CCB-A03.zip` во временный каталог;
  испорченные входы — копии `samples/`,
  изменённые в рантайме (`CorruptedCopy.U16`/`U32` — поле элемента таблицы
  явной ширины), в том числе испорченные `MSG_NUMEVENT`, `MSG_NUMHANDLER`,
  `AREAPTR`, `MSG_ANALOGCREAT`, `MSG_ANALOG_OBSE`, `MSG_ANALOGHANDL`, `RECMSG`,
  `ARCHIVES`, `MSG_LOGGER`, `FUNC_SEND_EMAIL`, `SCREEN`, `ADAPTVALUECHANG`,
  `GUI`, `VIEW_DYN`, `INFO_HANDLER` и длина в `PICTURE`; листы «Теги», «Сводка», «Системные события»,
  «Дискретные алармы», «Аналоговые алармы», «Классы алармов», «Группы алармов» и
  «Экраны»; записи `images.zip`). Отдельного процесса нет: `PanelRunner.Run(input,
  plc, outDir)` повторяет шаги окна шагами ядра — читает панель с `RunTranscript`
  (любая ошибка чтения — `PanelReadFailed`, файлы тогда не пишутся), без
  данных ПЛК (`plc` — `null`) шаг ПЛК пропускает, иначе вызывает
  `PlcDataReader.Read`, собирает данные листов тем же `PanelSources.From`, что
  окно, и пишет в `outDir`
  `panel_data.xlsx` (листы `PanelDataBook.TryBuild` — несобранный лист
  проваливает тест — → `ReportSheetsExporter.Export`). `PDATA.xlsx` и
  `images.zip` — только по запросу теста (`PanelRunner.SaveStrings`,
  `SavePictures`). Итог — `PanelRun(Output, Errors, Document)`: `Output` — строки
  `Info`, `Errors` — `Warning`/`Error` текста запуска, `Document` — панель;
  `HasProblems` — `Errors` не пуст. Проверки — `RunAssertions`: `Clean(run)`,
  `HasProblems(run)`, `HasLine`, `NoStackTrace`, `Unsupported` (строка ошибки с
  концом `PlcDataReader.UnsupportedConsequence` и «Данные ПЛК=не задан» на
  «Сводке»), слепок «Тегов», книга строк, `TablesMatch` — разбиение всех таблиц
  на элементы против `pdata.sha256` (`TableManifest`: хэши частей считаются в
  памяти, раскладка путей — как у бывшей hex-выгрузки). `TestDirectory` —
  временный каталог теста: каталог результата `out` (до запуска его быть не
  должно), `PanelDataWorkbook`, `StringsWorkbook`, `PicturesArchive`
  (`out/images.zip`). Каждый тест запускает `PanelRunner.Run` в своём
  временном каталоге (`flexrt-tests-<GUID>`) и удаляет его; общих запусков и
  своего тестового фреймворка нет; `data/out` тесты не трогают.
  `Integration/RealStepsTests` — копии `data/real/steps/` (вне git): каждая без
  предупреждений, тегов на 1 больше от шага к шагу; папки нет — тест падает.
  `Integration/InfoTextsReadTests` — `INFO_HANDLER`: образцы `samples/`
  (кроме `card/`) — таблица есть, пар нет, без предупреждений; `card/pdata.fwc` —
  2000 пар на `MSG_NUMEVENT` 0…1999, у каждой строка есть, все пустые; шаговые
  копии `data/real/steps-screen-props/` (`04`, `11`, `12`, `13`) и
  `data/real/steps-tooltip-langs/01_tooltip_langs.fwc` (вне git) — точные пары,
  имя экрана по номеру записи, текст `Screen_2` с CRLF, текст `998_LOGIN` на трёх
  языках; файла нет — тест падает; испорченные первое слово и N в копии
  `samples/pdata.fwc` — предупреждение с таблицей и смещением, без stack trace.
  `Integration/ScreensRunTests` — лист «Экраны» на образцах `samples/` (с цветом
  фона и колонками Tooltip) и испорченные `SCREEN` (в том числе N третьей записи
  3 — после объектов 8 байт: сводное предупреждение, все записи на листе, цвет
  `?`; вместе со сбоем пятой записи — сводное предупреждение о цвете не теряется
  и идёт перед предупреждением о сбое), `ADAPTVALUECHANG`, `GUI`, `VIEW_DYN` (число ссылок 0x30 или 3 — высота не помещается,
  пара `VIEW_DYN` записи `Overview` ведёт на другую таблицу или за последний
  элемент — предупреждение, Height Permanent area `?`; сломана запись `Overview` —
  предупреждение только от SCREEN); Height Permanent area 60 у Project1, 0 у
  CCB-A13 и A603A0097. Шаговые копии
  вне git — через `StepCopies` (папки `Tags`, `ScreenProps`, `TooltipLangs`,
  `Folder` и `Path`; нет папки или файла — тест падает; им пользуются и
  `RealStepsTests`, `InfoTextsReadTests`).
  `Integration/ScreenPropsRunTests` — лист «Экраны» по шаговым копиям (вне git,
  файла нет — тест падает): `steps-screen-props/02_bg_color.fwc` — цвет
  `Screen_1` 18, 52, 86 и заливка ячейки этим цветом; `13_tooltip_ui_plain.fwc` — подсказки как есть (CRLF
  ClosedXML читает из книги как `\n`, у Screen_1 — разметка Openness);
  `steps-tooltip-langs/01_tooltip_langs.fwc` — подсказка `998_LOGIN` в трёх
  колонках языков; `14_overview_color.fwc` и `15_overview_height.fwc` — строка
  Permanent area: цвет 52, 86, 120, Height 60 и 80, экраны — 800×420.
  `DamagedInputTests.BrokenUnparsedTable_Warns` — проверка раскладки таблицы без
  парсера (`TableLayoutCheck`). `Integration/LanguageColumnsTests` — языки колонок
  (`ReportTable.ColumnLanguages`) на `samples/a603/pdata.fwc`: языки панели
  0x409, 0x419, 0x415; у «Системных событий», «Дискретных алармов»,
  «Аналоговых алармов» (таблица строится напрямую — в a603 их нет) и «Классов
  алармов» и «Экранов» (Tooltip) язык — ровно у колонок с ним в заголовке, по
  одному на колонку, каждый язык — у одной колонки, у классов — у четырёх; у
  остальных листов книги языков колонок нет; на `samples/a603-classes/pdata.fwc` ячейка Alarm
  class своего класса несёт Display name на трёх языках (текст — первый
  язык), у стандартных классов текстов на языках нет. `Unit/Export/LanguageChoiceTests`
  — язык окна после открытия и перечитывания, `Unit/Export/ReportCellTests` —
  `ReportCell.DisplayIn`. Листы-таблицы сверяются слепком
  `SheetDump` (ячейки через ` | `, переносы строки — `\r`, `\n`), колонка листа
  классов — по заголовку на самом листе. `Unit/Export/LanguageText` сверяет
  название языка с данными культур этой машины (ICU/NLS), а не с текстом.
  `Extraction/` — `PlcDataReader` с `RunTranscript`: сбой сопоставления (после
  строки «Файл ПЛК: …» — предупреждение «… сопоставление с ПЛК: …»,
  сопоставление без проекта ПЛК) на
  `samples/plc/pdata-one-connection.fwc` с номером соединения −1 у связей в памяти.

## Данные вне git

- `data/` — `out/` (результат удалённой консоли; программа туда больше не
  пишет) и `real/` — реальные копии
  `pdata.fwc`, в том числе пошаговые `real/steps/` (V17, внутренние теги),
  `real/steps-v21/` (V21, PLC-теги), `real/steps-screens/` (V21, экраны
  Project1), `real/steps-screen-props/` (V21, свойства экранов и подсказки
  Project1) и `real/steps-tooltip-langs/` (V21, подсказка экрана A603A0097 на трёх
  языках). Каталог исключён из git.
- Вне репозитория, на Рабочем столе: проекты TIA `extract_backup_data\Project1`,
  `Project1_upload` (выгружен из PLCSIM), `Project1_plc_only`,
  `A603A0097_V21` / `A603A0097` (реальный, DB, 3 языка, Openness-эталон в
  `A603A0097\openness_export\`), `半自动驱动轴装配线03_06_2026[_V21]` (S7-1200).
