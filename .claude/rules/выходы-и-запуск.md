# Текст запуска, выходы, «Сводка», Excel

Установленное поведение и известные ограничения области (см. «Правила по областям» в
`CLAUDE.md`): не меняй без решения пользователя. Меняется код — меняются XML-документация и этот файл.

## Устройство

- Консольного приложения нет (решение пользователя, 2026-10-20): удалены
  `src/FlexRt` (`Program.cs`, `LogReporter`, Serilog, лог, переменные окружения
  `FLEXRT_*`, коды возврата), пакетный запуск ядра `ExtractionRun` и выходы,
  которые писал только он: папка `pdata` (hex таблиц TOC, `raw.hex.txt`), папка
  `images`, книга консоли с листом «Ошибки». Всё, что видит пользователь, — окно
  (`окно.md`); файлы пишутся только по кнопкам сохранения окна.
- `Extraction/RunTranscript` — текст запуска строками с уровнем
  (`TranscriptLine`: `Info`, `Warning`, `Error`) в порядке событий — вкладки Info
  и «Ошибки» окна; им же пользуются интеграционные тесты. Стек ошибки в текст не
  попадает. Интерфейса событий нет (был нужен консоли с логом; удалён решением
  пользователя 2026-10-20).
- `Extraction/PlcDataReader.Read(doc, plcPath, transcript)` — шаг данных ПЛК:
  проверка «не поддерживается», чтение проекта ПЛК, сопоставление тегов, ошибки
  ПЛК; сам ничего не пишет, строки кладёт в `RunTranscript`.
  Конец сообщения «не поддерживается» — константа
  `PlcDataReader.UnsupportedConsequence` («панель показана без данных ПЛК»).
- `Extraction/PanelSources.From(doc, path, files, plc)` — данные листов
  (`PanelDataSource`) для окна и тестов: с поддержанными данными ПЛК — их проект,
  сопоставление и источник; без них или при «не поддерживается» — сопоставление
  без проекта ПЛК и «Данные ПЛК» — `PanelSources.NoPlc` («не задан»).
- `ReadFailure` — ошибка чтения или непредвиденная (закрытый `IsReadError`) и
  текст ошибки (`Describe`; непредвиденная — «непредвиденная ошибка <тип>: …»).
- Файлы рядом с `pdata.fwc` (`ProjectCharacteristics.rdf`, `BuildInfo.txt`)
  не читаются: их читатель и строки «Модель панели», «Версия Runtime» «Сводки»
  удалены (решение пользователя, 2026-10-20).

## Установленное поведение

- Лист «Сводка» в `panel_data.xlsx` — первый, подпись в A, значение в B: файл
  панели, IP и маска панели (`DEVICE_OMSP` +0x0c, +0x10), языки (`0x419 — русский
  (Россия)`: код и название языка на нём самом), строки, теги, системные события,
  дискретные алармы, аналоговые алармы, классы алармов, группы алармов, экраны
  (`Экранов`), стартовый экран (`Стартовый экран`), картинки (`Картинок`);
  пустая строка; по строке на соединение (`Соединение <имя>` — `IP ПЛК …`;
  соединений нет — `Соединения с ПЛК` — `нет`);
  пустая строка; `Данные ПЛК` — `карта ПЛК: путь`, `PEData.plf: путь`,
  `не найден: путь`, `не прочитан: путь`; если данные ПЛК прочитаны — по каждому
  ПЛК имя, модель CPU (только с карты: `CPU 1515F-2 PN (6ES7 515-2FN03-0AB0)`),
  IP из данных ПЛК (с карты — из объекта «Network Parameters» CPU), затем число тегов ПЛК и DB. Нет
  файла или значения — «неизвестно», без предупреждения; элемент
  `DEVICE_OMSP` другой раскладки (короче 0x14 байт или начало не
  `01 00…00 03 00`) — тоже «неизвестно», без предупреждения. Без данных ПЛК
  «Данные ПЛК» — «не задан».

- XLSX: лист `0x<lcid>`, колонки `idx` и `str`, текст не превращается в
  формулу, строка длиннее 32767 символов обрезается, апостроф в начале
  текста сохраняется (ClosedXML снимает первый `'` как префикс текста Excel,
  поэтому `ExcelCell.Text` добавляет второй, а такой текст обрезается до 32766
  символов — ClosedXML проверяет предел до снятия апострофа); так же в
  `panel_data.xlsx`.
  `\r` в тексте пишется как есть и в Excel читается как `\n`.
- Листы `panel_data.xlsx` описаны один раз — `Export/PanelData/PanelDataBook`:
  по листу (`PanelDataSheet`) имя, раскладка «Сводки», условие наличия по
  панели, построители таблицы и статистики — в порядке книги; данные для
  построения — `PanelDataSource` (панель, проект ПЛК, сводка, сопоставление как
  `Lazy`: считается один раз, его ошибка повторяется «Тегам» и «Дискретным
  алармам»). «Сводка» и «Теги» есть всегда, листы алармов и «Экраны» — если в
  их таблице есть строки. Порядок листов закреплён тестом. Листы окно строит
  `PanelDataBook.TryBuild` — каждый отдельно, сбой листа — итог с ошибкой и
  пустым листом той же раскладки. Новый лист — строка в
  `PanelDataBook.Sheets` и узел дерева в окне (`PanelViews.Nodes`).
- Книги и картинки пишет окно (поведение — `окно.md`) через ядро:
  `panel_data.xlsx` и отдельный лист — `Export/PanelData/ReportSheetsExporter.Export`
  из готовых таблиц (`ReportSheet`; раскладка — по данным листа: признак
  «Сводки», есть ли статистика): «Сводка» — `SummarySheet.Write` из таблицы
  `SummaryRows.Table`, «Теги» — `TagsSheet.Write` из готовых статистики и
  таблицы, имя листа — из `ReportSheet.Name`, остальные — таблица с первой
  строки, как у листов алармов и «Экранов». Листа «Ошибки» нет; без листов
  книга не пишется (`ArgumentException`). `PDATA.xlsx` — `Export/Strings/XlsxExporter`;
  архив картинок — `Export/Pictures/PictureArchiveExporter`: записи в корне
  архива под именами `PictureArchiveExporter.EntryName` (`<таблица>_<n>.<png|jpg>`,
  n — номер элемента таблицы с единицы: `PICTURE_5.png`; то же имя показывает
  окно), байты как есть, в порядке `FwxDocument.Pictures`, без сжатия; файл уже
  есть — перезаписывается.
- Имена листов — константы `Name` классов `*Sheet`; имена файлов по умолчанию —
  `PanelDataBook.FileName` (`panel_data.xlsx`), `XlsxExporter.FileName`
  (`PDATA.xlsx`), `PictureArchiveExporter.FileName` (`images.zip`).
- Панель с несколькими соединениями с ПЛК и заданными данными ПЛК (файл
  `PEData.plf` или папка карты существует) сознательно не поддерживается
  (решение пользователя): после сводки панели в тексте запуска —
  `ОШИБКА: не поддерживается: соединений панели с ПЛК - N, а данные ПЛК заданы
  (<путь>) - сопоставление сделано только для панели с одним соединением;
  панель показана без данных ПЛК`; данные ПЛК не читаются, панель показана без
  них («Данные ПЛК» — «не задан»). Без данных ПЛК такая панель читается как обычно.
- Путь данных ПЛК — папка: это копия карты ПЛК (в ней `SIMATIC.S7S\OMSSTORE`),
  иначе файл `PEData.plf`. В строках `Файл:` и `Файл ПЛК:` текста запуска —
  фактически прочитанный путь.
- Непредвиденная ошибка при чтении проекта ПЛК или сопоставлении не обрывает
  чтение: «непредвиденная ошибка <тип>: …» в тексте запуска
  (`ПРЕДУПРЕЖДЕНИЕ: файл ПЛК - …`); сбой сопоставления — сопоставление
  повторяется без проекта ПЛК. Парсеры сами ничего не пишут.
